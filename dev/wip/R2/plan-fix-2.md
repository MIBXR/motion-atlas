# 决定：HUD 在昼夜过渡中的处理（案例与 day-night-flip、corner-hud 等所有用到 HUD 的巧思一起改）

设 n 为当前的 dayNight 值（0 = 昼，1 = 夜）。

1. **地图配色**：照旧随 n 平滑插值，不变。
2. **HUD 的颜色（文字色、辅助文字色、强调色、线条色）**：不再随 n 插值。
   - n < 0.5 时，整套取白天值；
   - n ≥ 0.5 时，整套取夜晚值。
   - 白天值、夜晚值就是现有插值两端的颜色。
3. **HUD 整体透明度**：乘以 `a(n) = clamp(|n − 0.5| / 0.25, 0, 1)`。
   - n 在 [0.25, 0.75] 区间内，HUD 先淡出到 0（n = 0.5），切换颜色后再淡入；
   - 其余时刻 a = 1。
   - 透明度只乘在 HUD 容器上，不影响地图与其他覆盖层。
4. **作用范围**：所有读取这套 HUD 昼夜色的部件，包括日序、日期、进度线、指南针、坐标、时钟、时区、NOW PLAYING、歌词、步进器、比例尺。署名不在 HUD 容器内，保持现状，始终可见。
5. **案例 `demos/cases/map-pilgrimage/`** 照此修改；复制了 HUD 的巧思（corner-hud、day-night-flip、seekable-timeline，以及其他含 HUD 部件的）同步修改。
