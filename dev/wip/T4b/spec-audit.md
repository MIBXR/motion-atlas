# T4b 方案约束核查

范围：源代码与 inventory 的只读核查、标记时间与固定镜头的纯计算。本文的几何结果尚未经过浏览器验证；未修改十二个巧思的实现。

## 需要决定的事项

### 1. seekable-timeline 控制条字号

- **已核查事实**：源控制条 DOM/CSS 位于 `demos/cases/map-pilgrimage/motion-kit.js:2033–2065`，`:2048` 指定 `font:13px/1`。inventory 对应范围为 `dev/shots/T4b/inventory/README.md:6753–6785`，其中 `:6768` 保留该字号。
- **方案约束**：3.11 要复制该控制条并放入舞台；2.8 要求横屏至少 24px、竖屏至少 36px，并禁止自行调整不足的字号。
- **冲突**：原样复制 13px 控制条不能满足 2.8。方案所列 2093–2120 行并非控制条完整结构与样式位置；完整实现可从上述实际源码定位。
- **选项**：允许该控制条沿用源 13px，并接受它无法通过当前 strict-fonts 验收；或授权该控制条分别使用横屏 24px、竖屏 36px，保留测试阈值。

### 2. route-draw-marker 标记片段与完成态 hold

- **已核查事实**：源 `drawMarkers()` 的英文打字从标记入场后 0.12s 开始、历时 0.5s；日文从入场后 0.55s 开始、历时 0.3s。当前源码为 `demos/cases/map-pilgrimage/script.js:1440–1446`；稳定的 inventory 证据为 `dev/shots/T4b/inventory/README.md:2420–2425`，摘录源行号 1399–1404。`motion-kit.js:121–123` 用 `Math.round(p × 字符数)` 决定已显示字符数。
- **方案约束**：3.3 的标记窗口均为 0.45s，naraPark 在巧思 7.0s 开始，源窗口 40.8→41.25；巧思 7.5→9.0 要 hold 完成态。2.2 要求 hold 静止在前一段末尾的 caseT，复制函数内部逻辑不改。
- **推导**：NARA PARK 共 9 个字符。给定窗口结束时（巧思 7.45s / caseT 41.25），英文仅 6/9 字符，日文尚未开始。即使把源动画继续到巧思 7.5s，英文也仅 7/9 字符、日文 opacity 为 0。英文首次全字约为巧思 7.592222s，英文打字进度到 100% 为 7.62s；日文淡入区间为 7.55→7.85s。其他 0.45s 标记窗口同样不足以走完源标签动画。
- **冲突**：严格保留片段与时长会得到未完成的标签；7.5s 开始的完成态 hold 不能同时成立。
- **选项**：保留指定截断窗口并接受标签未完成；或授权延长标记窗口与最后 hold 起点。不能在未授权时缩短源函数的打字或淡入时长。

### 3. route-draw-marker 固定镜头与 JR 奈良站名

- **已核查事实**：四站坐标位于 `demos/cases/map-pilgrimage/config.js:77–82`；JR 奈良的 `minZoom` 在 `:81` 为 13。源标签显隐逻辑见当前 `script.js:1440–1442`，inventory 为 `README.md:2421–2423`。zoom ≤ 12.75 时 JR 奈良标签整体不可见，圆点不受这一标签条件影响。
- **方案约束**：3.3 要在 bearing 0、pitch 0 的固定镜头中框住四站外包框，四边各留舞台尺寸 12%；并要求站点标记弹入和双语站名表现。
- **纯计算结果**：采用源 Mercator 坐标与 `512 × 2^zoom` 世界尺寸，按四站外包框和 76% 可用宽高求得横屏 zoom ≈ 9.755836、竖屏 zoom ≈ 9.920639。二者均低于 12.75，因此原样复制源逻辑会隐藏 JR 奈良站名。源公式见当前 `script.js:91` 与 inventory `README.md:2198` 的世界尺寸摘录。此结果未做浏览器实测。
- **需要确认的预期**：如果四站都必须展示双语站名，需要授权在此固定镜头内忽略 JR 奈良的 `minZoom`；若保留源规则，则接受该站只显示圆点。没有自行选择其一。

## 复算

标记入场后经过时间记为 `u`，英文字符数为 `round(clamp((u − 0.12) / 0.5) × 9)`。首次全字满足 `u ≥ 0.12 + 0.5 × 8.5 / 9 ≈ 0.592222`；日文淡入设定为 `u=0.55→0.85`。

```js
const stops = [[135.24433,34.4364],[135.75878,34.98513],
  [135.81901,34.68079],[135.8398,34.6853]];
const points = stops.map(([x,y]) => [(x+180)/360,
  (1-Math.log(Math.tan(Math.PI/4+y*Math.PI/360))/Math.PI)/2]);
const dx = Math.max(...points.map(p=>p[0]))-Math.min(...points.map(p=>p[0]));
const dy = Math.max(...points.map(p=>p[1]))-Math.min(...points.map(p=>p[1]));
for (const [orient,w,h] of [['landscape',1920,1080],['portrait',1080,1920]]) {
  console.log(orient, Math.log2(Math.min(w*0.76/dx,h*0.76/dy)/512));
}
```
