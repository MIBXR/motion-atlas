## 已看过的真实画面（公开攻略截图，仅本地查看，未下载入库）

1. **集成工业系统（AIC）建造视角**（endfield.gg 蓝图攻略）
   - 左上：圆形小地图，标题 `AIC`；下方是任务目标（黄色圆点 + 白字），以及距离。
   - 顶部中间：资源计数胶囊（图标 + 数字，两组）。
   - 右上：一排圆形图标。
   - 右侧：一列圆形按钮。
   - 场景交互提示：圆形图标外加黄色描边光环；中上方有提示胶囊“Enter Top View”，带按键标识。
   - 场景物件：黄色发光的地面导轨与传送带，白灰色工业结构。
2. **蓝图俯视图 / 分享**
   - 底板：浅灰方格（坐标纸）。
   - 传送带：黄色，带点状纹，直角转弯，十字分流节点是带箭头的深色方块。
   - 设备：白色方块，内嵌深色圆形图标；大设备是带刻度边框的长方体。
   - 左上标题：`// Share Blueprint`。
   - 右侧：深灰详情面板，含 Blueprint Details、设施缩略图网格、`+6` 计数。
   - 左下：Sharing Code 加复制图标。
   - 右下：`ENDFIELD` 标志，下方带彩色条。
3. **弹窗（导入蓝图）**
   - 一条横贯屏幕的白色条带，背景压暗；标题居中；输入框为浅灰底，右侧有图标按钮。
   - 胶囊按钮：取消用深灰底 + ⊗，确认用亮黄底 + ◎；胶囊内左侧有一条细横线装饰。
4. **寻访（抽卡）**
   - 左上：`// HEADHUNTING`；卡池标题放在方括号框里，左上有彩色刻度条，副标题是剩余次数。
   - 背景：黄色大号倾斜英文标题；角色立绘，名牌为小方块图标 + 名字。
   - 左侧：竖排卡池标签。
   - 右上：资源胶囊（图标、数字、+），关闭 ×。
   - 右下：黄色 `Headhunt×10` 主按钮；上方是剩余次数（大号数字）。
   - 底部：按键提示条。
   - 提示卡：白边框卡片，配黄色小胶囊按钮“Go to Event”。
5. **探索 HUD 与交互菜单**
   - 交互菜单：半透明深色列表，标题为设施名 `Automation-Core`；选项为 `Start Transmission`、`Protocol Management`，每项前有圆形图标，左侧有按键提示。
   - 底部中间：快捷物品栏，一排方格。
   - 右侧：一列圆形按钮，含按键提示。

## 风格要点（初步）

- 主色是浅灰、白配深灰 / 近黑，强调色为亮黄（偏柠檬黄）；彩色刻度条（多色细条）用作品牌点缀。
- 标题前缀用 `//`；方括号框；斜切角；细线装饰；圆形图标按钮；胶囊按钮。
- 信息密度高，但层级清楚：大标题 + 小号大写英文副标题。
