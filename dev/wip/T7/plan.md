# 5. 实现约束

- 文件：`demos/cases/industrial-protocol/` 下的 `index.html`、`style.css`、`script.js`、`config.js`、`motion-kit.js`（build 同步），可以加 `assets/`（只放自绘 SVG）。旧实现全部替换。

  - 界面用 DOM + CSS；
  - 设备与图标用内联 SVG（自绘，几何风格）。
