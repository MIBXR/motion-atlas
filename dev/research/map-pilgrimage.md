# 地图巡礼 · 游戏过场式旅行影像：逐帧研究

- 参考：【眩晕瘫坐 旅游时拍的素材给Opus5.5剪出来是这样】（哔哩哔哩，<https://b23.tv/eBjaN0O>），画面署名 @DWTornier
- 素材：用户下载的本地成片，151.21 秒，1920×1080
- 观察日期：2026-10-14（初次）、2026-10-16（打磨第一轮复看：全片粗扫、9 段转场细扫、21 张全分辨率帧）
- 方法：浏览器 `<video>` + Canvas 取帧。全片每 2 秒一帧（76 帧）；转场处每 0.25–0.3 秒一帧（片头昼夜与片名、卡片→全屏、全屏动画回忆、夜→昼与章节框线、动画→实景分屏）；关键画面按 1920 宽全分辨率读取 HUD 文字。
- 证据等级：结构、文字内容、版式与时间点为 **逐帧实测**；具体缓动曲线与毫秒数为本地拟合（标注“约”）。原片使用的工具链未公开，本笔记不做推断。

## 一句话结构

一个稳定的**世界层**（地图）+ 一套持续更新的**信息层**（四角 HUD）+ 有节制的**模式切换**（卡片 / 全屏实拍 / 全屏动画回忆 / 分屏对比）。地图永远是底座，HUD 永远在报时；只有高光才允许离开地图，而离开时 HUD 也跟着走。

## HUD 规格（0:16.5 全分辨率读数）

- 左上：`DAY 01 / 07`（DAY 粗体、01 为强调色、/ 07 等宽小字），下方 `MON · SEP 28 2026`（等宽、大字距），再下方一条短粗下划线。
- 顶部：一条贯穿全宽的细线，左段为强调色（随行程推进）。
- 右上：`34.4320°N 135.2304°E` 与 `ELEV 0 M · Z 10.9`（等宽小字，Z 为地图缩放级别），右侧大号等宽时钟 `11:33` + 角标 `JST`。
- 右侧：白色胶囊计数徽章（吉祥物头像 + `YUI SPOTTED` + `×2`）。
- 左下：均衡器图标 + `NOW PLAYING`，曲名粗体 — 艺人常规；其下一行加粗歌词与一行灰色副歌词。
- 右下：`SEOUL — KANSAI — KYOTO — TOKYO` 步进器，已到达节点实心；最底一行地图署名。

## 节奏分析

- **事件密度**：地图段落平均每 4–6 秒出现一个新事件（新卡片、新地名、计数、便签、歌词换行），观众始终有新信息可看，但同一时刻只有一个主事件。
- **模式切换**：约每 10–15 秒离开一次地图（全屏实拍/动画/对比），全屏段落持续 1.2–7 秒；回到地图后至少留 1–2 秒“呼吸”。
- **能量曲线**：开场低 → 片名第一峰 → 旅程中速 → 回忆与对比为最高峰 → 意外事件制造第二个尖峰 → 结尾回落。Demo 的能量曲线按同样形状设计（见条目 `energy`）。
- **一致性来源**：所有模式共用 HUD、颗粒与强调色系统，所以“切换”像在同一个系统里切视图，而不是不同素材的拼接。

## 画面细节

- 原片就是一段日本旅行（首尔 → 关西机场 → 西宫 / 京都 / 宇治 → 东京），地图 HUD 用 JST；城市近景都有成片的 3D 建筑与铁路细线，这也是 Demo 改用日本路线的依据之一。
- 章节不只换强调色：一种是屏幕四角框线（带方块角标），另一种是底部斜纹警示胶带 + 整张地图染上章节色；Demo 两种都做了（鸭川用框线、奈良用胶带 + 网点）。
- 手写便签出现时，地图整体被一层浅色纸面“洗”淡，便签像贴在地图上；Demo 用 `wash` 层复现。
- 收集托盘在右下角，是一排小缩略图逐个点亮；Demo 改为与步进器同列的车站印章（原创形式，不复制角色收集）。
- 竖排地名在原片是粗黑体；Demo 改用明朝体（与“巡礼 / 古都”的气质一致，属于本地设计选择）。
