## 一、调研发现

1. **控制条点击丢失的根因（已实测）**：旧 `controls()` 在每帧回调里执行 `btn.innerHTML = playing ? ICON.pause : ICON.play`。按下时命中的是 SVG `<path>`，下一帧它被替换，抬起时命中新节点，浏览器不派发 click。用 CDP 真实鼠标事件在播放中连点 20 次：按压 90ms（真人常见时长）**0/20** 生效，按压 5ms **6/20** 生效——这就是“有时点不动”：按得越慢越容易丢。站点 `assets/library.js` 第 328 行 `play.innerHTML = …` 是同一问题（T2 修）。
2. **旧声音**：`sound()` 只有 `tone` / `noise` 两个原语（裸振荡器 + 指数包络），直连 `destination`，无总线、无限幅、无混响；各 Demo 自己在 `tl.on` 里做前瞻排程（beat-lyric 用 120ms）；页面隐藏时直接 `disable()` 且不会自动恢复；15 个 Demo 用到 `sound()`（`tone` 67 处、`noise` 21 处）。
3. **旧布局**：47 个 Demo 全部是 `timeline + expose + controls`，舞台用 `vw/vh/clamp()` 自适应；43 个 Demo 目录有低于 24px 的静态字号（旧标准 12px）。
4. **DynamicsCompressorNode 不能当砖墙限幅器**：规范要求它自带“自动补偿增益”（full-range gain 的 0.6 次方倒数），高阈值高比率时反而抬高输出。所以最后一级改用 WaveShaper 软削波曲线保证天花板。
5. **混响尾音残留**：只淡出各声部时，已送进卷积混响的尾音（约 2.6s）在暂停后继续回响。改为：被停止的声部送过混响且尾音未结束时，连同混响链一起换新。
6. **持续音断档**：暂停后继续、跳转、换画幅时，早于当前时刻开始的铺底 / 环境底 / 上升音不会被重新排程，音乐“掉底”（换画幅后实测输出从 -6.8 掉到 -25.9 dBFS）。改为对持续型音色做“中途接续”（见 2.3）。
7. **`scripts/lib/cdp.mjs` 的进程挂住**：`Page.eval` 用 `Promise.race` 搭配一个从不清除的 `sleep(timeout)` 计时器，每个脚本结束后 Node 进程要再挂 60–120 秒才退出（冒烟、渲染、截图都受影响）。清掉计时器后，同样的离线渲染脚本总耗时从 2 分 0 秒降到 2.9 秒。
8. **iframe 内开启声音的可行性**：在无头 Edge 上用 `--autoplay-policy=document-user-activation-required` 和真实鼠标事件实测，结论见 4.3 末尾的场景表与第五节“给 T2”第 3 条。同源子框架会继承父页面的“粘性激活”，所以站点按钮里发消息就能开声音，即使 iframe 之后重新载入也有效。

## 二、设计决策与 API

### 2.1 舞台

```js
const stage = MotionKit.stage({ root: '#stage' });        // orients 默认 ['landscape','portrait']
function layout(orient) { /* 按画幅重建几何（坐标来自 config.layout[orient]） */ }
layout(stage.orient);
stage.on('orient', layout);                                // 切换：先重建几何，kit 再 seek(当前时刻) 重绘
canvas.addEventListener('pointerdown', (e) => { const p = stage.toStage(e.clientX, e.clientY); });
```

- 根节点固定像素尺寸，缩放只在根节点 transform 上（`translate(取整像素) scale(s)`），所以内部库测到的 `clientWidth` 恒为舞台像素；`data-orient` 同时挂在 `<html>` 与根节点，CSS 写两套构图。
- 优先级：`?orient=` → 宿主 `motion:orient`（舞台创建前收到也会记住）→ 自动（带 ±5% 迟滞，只有自动模式随窗口变化）。宿主 / 控制条 / API 的切换会关闭自动模式。
- 切换顺序：尺寸与属性 → 重新缩放 → `onOrient` / `on('orient')` → 声音硬停 → 发 `motion:orient` → `tl.seek(tl.time)`。播放状态与时刻不变。
- 只支持一种画幅的 Demo：`orients: ['landscape']`，宿主请求竖屏时回报 `{type:'motion:orient', orient:'landscape', rejected:'portrait', supported:[…]}`。

### 2.2 时间轴与 `__motion`

- `timeline.on(fn)` 保持原义；新增 `on('play'|'pause'|'seek'|'rate'|'loop'|'end', fn)`（seek 回调 `(to, from)`，在 render 前触发）；`loop` 可读写；`seek(NaN)` 不再产生 NaN。
- `expose()` 新增：`ready`（Promise）、`progress`、`orient`、`orients`（空数组 = 旧版自适应 Demo）、`setOrient()`、`stage`、`audio`（离线接口，未挂乐谱时为 null）、`kit`；`motion:ready` 改为在预加载完成后发送，并带 `orients / orient / markers / sound / title / kit`。
- `MotionKit.start(tl, { t, reduced })`：统一处理 `?t=`、减少动态与自动播放（等 ready）。

### 2.3 声音

```js
const SCORE = [
  { t: 0, voice: 'air', dur: 9.5, vel: 0.6 },                         // 环境底
  MK.audio.pattern({ bpm: 120, from: 2, to: 7, tracks: { kick: 'X...x...X...x.x.', clap: '....X.......X...', hat: '..x...x...x...x.' } }),
  { t: 2, voice: 'impact', vel: 0.9 }, { t: 2, voice: 'sub', note: 'A1', dur: 1.2 },
  { t: 2, voice: 'pad', notes: ['A2','E3','A3','C4','E4','G4','B4'], dur: 5, attack: 0.25 },
];
MK.audio.attach(tl, SCORE);            // 播放时前瞻 120ms 排程；暂停 / 跳转 / 换画幅立即停止并从新位置继续
MK.audio.play('blip', { note: 'E6' }); // 交互输入即时触发
await MK.audio.renderOffline(SCORE, 9.5); // 同一套音色离线渲染 → { peakDb, rmsDb, wav(), base64() }
```

- **链路**：音色 → 事件增益 × 校准电平 → 声像 → 总线（music / sfx / ui；bed 属于 music，受侧链闪避）→ 主增益 0.65 → 压缩（-14dB、3:1、软膝 10dB）→ 微调 → 软削波天花板 → 输出；混响发送 → 高通 220Hz → 卷积（程序生成：早期反射 + 指数衰减、随时间变暗的双声道噪声尾，RT60 2.2s）。
- **天花板**：|x| ≤ 0.6 完全线性，之上 tanh 软膝趋近 -1 dBFS，超出 ±1 的输入被钳到曲线端点 → 输出峰值数学上 < -1 dBFS（不依赖压缩器）。
- **音色**：每个都是 `(ctx, out, when, params) → 结束时刻`；校准电平写在 `audio.meta[name].level`，使力度 1 时峰值大致为：鼓与冲击 -5 ～ -10 dBFS、界面音 -14 ～ -18 dBFS、铺底按 RMS -21 ～ -29 dBFS（实测表见 `dev/shots/T1/voices-final.txt`）。参数表在 `docs/pipeline.md` 4.4。旧 `tone` 的响度与旧版一致（g=0.2 时 -20.2 dBFS，旧版 -20.0）。
- **确定性**：噪声缓冲、混响脉冲、颗粒类音色的随机都用固定种子，事件种子由音色名与 `t` 派生——离线渲染逐次一致。
- **调度器**：锚点（时间轴时刻 ↔ ctx 时刻）+ 游标；由时间轴每帧回调与 40ms 定时器共同驱动；偏移 > 80ms（掉帧）时撤销未开始的声部并重新对齐；支持 rate 与 loop；与当前相差不到 1 帧的 seek 视为重绘，不打断声音。
- **硬停**：本乐谱的声部 12–15ms 线性淡出并 stop，未开始的直接静音取消；侧链复位；送过混响且尾音未结束时整条混响链换新（只在需要时做，拖刻度条不会反复重建）。
- **持续音接续**：`META.resume` 标记 pad / drone / air / wind / riser / reverse / alarm；硬对齐时把“开始于当前时刻之前、此刻仍应发声”的事件以 `offset` 重新触发（80–120ms 淡入；riser / reverse 的扫频与渐强从对应进度继续，alarm 保持交替相位）。离线渲染从中途开始时同样处理。
- **开关与状态**：`enabled`（用户意图）与 `state`（`off` / `on` / `blocked`）分开；被自动播放策略挡住时绑定一次性手势兜底；后台挂起、前台恢复；状态变化发 `motion:sound`。
- **兼容**：`sound()` 返回同名接口，`tone/noise` 变成两个音色走新链路，与新引擎共用开关（站点的 `motion:sound` 对旧 Demo 同样有效）；旧 Demo 自己排程的音效在时间轴暂停 / 跳转时也会淡出。

### 2.4 预加载

```js
MK.preload([MK.preload.fonts(), MK.preload.image('a.jpg'), { label: '地图瓦片', weight: 4, run: prefetchTiles }]);
```

任务失败 / 超时只警告；进度写 `<html data-motion-loading>`、派发 `motion:loading` 事件、向父页面发消息；`expose()` 之后同一轮登记的任务也会被 `ready` 等到。地图类的预取做法写在 `docs/pipeline.md` 第五节。

### 2.5 控制条

按钮只创建一次，状态变化时切 `data-playing / data-sound / data-orient` 属性（CSS 显隐对应 SVG），图标 `pointer-events: none`；焦点在按钮上时空格 / 回车交给按钮本身，避免与全局快捷键双重切换；新增画幅按钮（显示“将切换到”的画幅）与声音按钮（`blocked` 时半透明）；窄屏自动收缩（390px 宽实测不溢出）。

## 五、给后续子任务的使用说明与注意事项

### 给 T2（站点）

1. **iframe**：保持同源，加 `allow="autoplay"`。读写 `iframe.contentWindow.__motion` 照旧；画幅与声音用消息：父 → Demo `motion:orient` / `motion:sound` / `motion:query`；Demo → 父 `motion:ready` / `motion:orient` / `motion:loading` / `motion:sound`（字段见 `docs/pipeline.md` 第六节）。
2. **画幅切换**：收到 `motion:ready` 后看 `orients`：长度 > 1 才显示横 / 竖按钮；空数组是未迁移的旧 Demo（自适应布局），不显示。点击发 `motion:orient`，以回报的 `motion:orient` 为准。也可以在 iframe 的 src 上带 `?orient=`（重新载入时用）。详情页给舞台留出 16:9 / 9:16 的容器即可，Demo 自己 letterbox。
3. **声音**：开关的 click 里发 `{type:'motion:sound', on}`（或直接 `contentWindow.MotionKit.audio.enable()`）；每次 iframe 载入并收到 `motion:ready` 后，按用户上次的选择再发一次（实测无需新手势）。根据 `motion:sound.state` 显示：`blocked` 时提示“点击舞台启用声音”。`MotionKit.audio.meter()` 可做电平指示。
4. **加载状态**：`motion:loading.progress` 0–1；`motion:ready` 之前可以显示加载中，但不要阻止拖动（seek 在资源未就绪时也安全）。
5. **暂停按钮**：`assets/library.js` 的 `paint()` 每帧 `play.innerHTML = …` 必须改成状态变化时才更新（两个 SVG 常驻、切换属性显隐），图标 `pointer-events: none`。可以用 `dev/shots/T1/clicks.mjs <url> 90` 的同样方法验证（它点的是 kit 控制条，改选择器即可）。
6. 预览图：`data/catalog.js` 的条目多了 `previewPortrait`（迁移前为 null）。

### 给 T3（节奏实验室）

- 节拍器直接用 `MotionKit.audio`：`pattern()` 支持 `div`（细分）、`swing`（0–1）、`offset`、重音（`X`/`x`/`o`）；改 BPM / 细分时 `sched.set(newScore)`；A/B 对比可以挂两份时间轴或用 `setMix`。即时响应用 `audio.play()`。
- 导出同步：`audio.renderOffline(score, dur)` → `wav()`，与画面同一套音色。

### 给 T4–T12（案例与巧思迁移）

1. 从模板起步：`stage()` → `layout(orient)` 重建几何 → `preload()` → `timeline` → `audio.attach(SCORE)` → `expose` → `controls` → `start`。旧 Demo 的 `const sfx = MK.sound()` 可以先保留（兼容），但声音设计请改写成乐谱，这样 `render.mjs --audio` 才能导出。
2. 版式：舞台里不要再用 `vw / vh / % / clamp()` / 媒体查询；横竖两套构图分别写；字号横屏 ≥ 24px、竖屏 ≥ 36px（`[data-orient="portrait"]` 选择器下的规则会按 36px 检查）。
3. 对齐：几何点由同一个坐标函数计算并取整；HTML 标签的锚点也从同一组坐标来；文字带衬底，线条终点停在衬底外缘。冲击抖动这类整体位移要让图形层与文字层同步。
4. `visibility: visible` 写在子元素上会盖过父层的 `hidden`（模板里踩过：光标在收尾卡上露出来），闪烁 / 显隐用 `opacity`。
5. 交互 Demo：指针坐标先 `stage.toStage()`；真实输入的反馈音用 `audio.play()`，自动驾驶的声音写在乐谱里。
6. 持续型声音（pad、drone、air、wind、riser、reverse、alarm）一定要写 `dur`，引擎才能在暂停后继续、跳转、换画幅时从中途接上。
7. 地图（T4）：预加载里按相机关键帧（含飞行途中采样点）`jumpTo` + `once('idle')` 预取各级瓦片并调大瓦片缓存；渲染模式 render 返回 Promise 等待，实时模式降级淡入。
8. 验证命令：`node scripts/smoke.mjs --only <ids> --strict-fonts`（两种画幅）、`node scripts/shot.mjs <url> --orient portrait --t …`、`node scripts/render.mjs <demo> --orient portrait --audio-only`（看峰值 / RMS / 削波）、`node scripts/check.mjs`。
9. 新的 Demo 若需要 kit 新能力，写进报告由主任务决定（kit 只有 T1–T3、T13 能改）。

## 六、遗留问题与说明

1. **ffmpeg 不在本机**：MP4 音画合成只验证了命令拼装（脚本打印的命令已核对参数），未实际合成。
2. **未实际试听**：环境没有音频输出，音色质感靠合成手段（噪声塑形、FM、包络、滤波扫频、饱和、立体声展开、卷积混响）和离线测量（峰值、RMS、时长、过零率）保证；`dev/shots/T1/voices-gallery.wav`（67 秒，全部音色依次排开）和两个模板的 WAV 供主任务或用户试听，必要时再调 `audio.meta[name].level` 或参数。
3. **Canvas 文字的运行时字号**无法从 DOM 读取：`check.mjs` 只能按 24px 静态粗查 `ctx.font`（不区分横竖），竖屏 36px 需要在截图里人工确认。
4. **旧 Demo 的竖屏**：未迁移前 `?orient=portrait` 不生效（`orients` 为空），smoke 只跑一遍；`render.mjs --orient portrait` 会提示“只是自适应布局”。
5. **站点刻度条暂停按钮**属于 T2；本任务只修了 kit 控制条。
6. 冒烟测试里“播放 1.5 秒后时间应前进 > 0.5 秒”的检查在机器高负载时可能误报（时间轴每帧最多前进 0.1 秒）：并行跑其他浏览器测试时 industrial-protocol、ink-bleed 各误报过一次，单独复跑通过；最终验证是在无其他负载时跑的。
7. 后台标签页的验证用的是“改写 `document.hidden` 并派发 `visibilitychange`”的模拟，真实切后台由浏览器节流行为决定，逻辑相同。
