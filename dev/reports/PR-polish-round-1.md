# 第一轮打磨：固定画幅、合成音频、站点控制与两个案例

## Summary

让两套固定构图、声音和加载状态贯通 Demo、站点预览与成片导出：

```text
MotionKit 舞台 / 乐谱 / 预加载
  → 站点详情页、节奏实验室
  → 地图巡礼（60s）与档案终端（64s）
  → 横竖预览、带声音的视频
```

- **T1**：1920×1080 / 1080×1920 固定舞台、WebAudio 合成与同谱离线 WAV、加载协议；渲染 / 截图 / 检查脚本支持两画幅，旧音效由共享 kit 兼容。
- **T2**：详情页舞台和时间轴首屏显示，横竖切换保持时刻，声音、加载进度、稳定的播放 / 暂停和全屏控制。
- **T3**：多音色节拍器、拍号 / 细分 / 摇摆、A/B 吸附、首拍偏移、量化强度、打拍录入、曲线对拍及 CSS / MotionKit / Prompt / WAV 导出。
- **T4a / T5**：日本关西路线、渐进地图缓冲与原创场景；FIELDWORK 五类四十份档案、无线信号开场、双轴循环、四向过渡与读取解密。
- **T13**：竖屏版权始终可读、40 份摘要均衡折行；修复地图收尾背景、引线标签状态、星空透明度、路线端点缓存与投影切换的 seek 依赖；修正 smoke 旧声音标签、CDP 断连等待及手机实验室回顶按钮遮挡，同步指南与管线说明。
