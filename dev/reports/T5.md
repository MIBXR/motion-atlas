# T5 交付报告：档案终端（循环阵列 · 四向过渡 · 两套构图 · 合成乐谱）

本报告覆盖案例 `archive-os` 的调研、实现和交付验证。关联巧思本轮保持不变。案例完整时间轴为 64 秒，使用原创 FIELDWORK 品牌及四十份原创档案，保留参考的双轴循环、列内选择记忆、连续轨道、选中波浪与详情解密。

竖屏阵列和横竖数据曲线按当前几何独立构图。当前版本的连续三轮smoke、行为与布局探针、构建、预览复拍、两段视频及视觉复核均已通过，第四节记录 `fix1` 的实际证据。

## 〇、摘要

- **原版实跑取证**：RhineLabUI 固定提交 `12cc5e4013acb9408f753ff71de6b8492299b7c8`；读取源码、许可、署名及文档，在隔离副本实际运行，保存 21 张原版截图与逐步状态。原参考目录未修改。
- **开场**：沿参考 25fps 阶段时点组织接入、身份、扫描、欢迎，21.92 秒进入阵列。无线信号为自绘 SVG「点 + 三条同心弧」，逐格点亮；该本地参考提交未提供标准 WiFi 图标，因此明确把无线形态归为用户指定的原创改写。
- **循环与四向**：五列×八档，行列内容索引与连续物理坐标分离；上/下/左/右均有方向一致的实体位移、抬起与波浪。25–47 秒共十二次方向事件，完成行首尾回绕、向右一圈及向左一圈，回到起点 FW-001。
- **固定画幅**：横屏 1920×1080、竖屏 1080×1920 单独构图；竖屏阵列区高820px，占画幅42.7%，其中SVG实际高700px，占画幅36.5%。编号与标题并排，保留摘要、三指标、全宽曲线及批注。舞台字号下限分别为24px与36px。
- **全宽曲线**：横屏曲线744×64px、竖屏952×56px，viewBox与实际尺寸一致，网格覆盖整个栏宽；半径4px的端点标记完整落在栏内，切换画幅时重新绘制。
- **声音与预加载**：系统字体通过 `MotionKit.preload.fonts()` 就绪后开始；`MotionKit.audio` 原创环境、配乐及事件乐谱共 206 个事件，`motion:ready` 实际报告 `sound: true`。
- **证据边界**：当前构图的验收结果待 `verify-fix1.json` 与连续三轮smoke补齐；既有结果不作为本版构图已通过的依据。seek检查分别记录DOM和PNG差异，不将DOM一致写成所有截图逐字节相同。

## 二、设计与时间轴

### 2.1 64秒演示

| 时段 / 标记点 | 画面与行为 |
| --- | --- |
| 0–1.8s | 白场待机，建立终端接入状态 |
| 1.8–21.92s | 逐字访问、原创无线图形、身份处理、授权扫描、欢迎及白场交接 |
| 21.92–25s | 等轴阵列入场，FW-001稳定展示 |
| 25s / 27s | 上行首尾回绕至FW-008，再下行回FW-001 |
| 29 / 31 / 33 / 35 / 37s | 向右切五列：FW-009→FW-017→FW-025→FW-033→FW-001 |
| 39 / 41 / 43 / 45 / 47s | 向左切五列，完成反向闭环并回FW-001 |
| 50–57s | 抽取、对角扫描、玻璃清晰化及正文揭示；54.147s开始自上而下揭示 |
| 57–60s | 返回阵列，保持起点选择 |
| 60–64s | 归档收尾与音乐终止 |

`render(t)` 的输入为绝对时间与有序事件列表。轨道、升降、波浪、文字、扫描与收尾由这些输入重建；不使用实时随机数或累计帧状态。横纵轨道共用事件阶跃响应，既维持连续运动，也允许倒序定位。

### 2.2 档案、排版与交互

品牌为 FIELDWORK，五类分别为光学研究、材料实验、环境观察、声学记录、空间测绘，每类八份，编号 FW-001–FW-040。每份有原创中英文标题、分级、时间戳、作者、摘要、批注、三项指标和十二点序列图。

横屏把阵列放左侧、档案与数据放右侧，详情采用并列结构。竖屏以高阵列和紧凑档案组织上下结构，阵列区与其实际SVG高度均落在画幅35–45%的范围内。功能按钮使用SVG箭头并保留可访问名称。`MotionKit.stage()` 管理固定画幅与等比适配，字体和内容按各自画幅排版。

竖屏高度分配如下，坐标均为1080×1920舞台内的绝对像素，页眉、阵列、导航与档案区之间留出16–20px间隙：

| 区域 | 纵向范围 | 高度 / 画幅比例 | 构图职责 |
| --- | --- | --- | --- |
| 页眉与会话 | 0–240px | 240px / 12.5% | 品牌、说明、会话授权及时间；隐藏单独的ARCHIVE OS副行 |
| 阵列外框 | 260–1080px | 820px / 42.7% | 顶部阵列说明、实体阵列与底部状态；满足阵列35–45%画幅要求 |
| 阵列SVG | 314–1014px | 700px / 36.5% | 等轴列向量[178,-62]、行向量[-48,48]；选中档案顶面完整置于可见区域 |
| 行列导航 | 1096–1160px | 64px / 3.3% | 四向按钮、八档刻度与列名 |
| 档案面板 | 1176–1820px | 644px / 33.5% | 编号/标题并排，元数据、两行摘要、三指标、曲线和两行批注 |
| 页脚与底部留白 | 1820–1920px | 100px / 5.2% | 状态页脚与画面下缘间隔 |

竖屏档案面板使用952px宽度。分类行右侧放208×44px的「读取」按钮；下一行左侧356px编号、右侧552px标题并排，独立英文标题隐藏。摘要取完整首句，最多37字，以36px字号、44px行高排两行；三项指标、952×56px全宽曲线和两行批注保留。没有以缩小字号容纳内容，竖屏文本仍至少36px。

读取状态复用上方展示区：仪器SVG容器高700px，保留780×620的原比例viewBox，不作纵向压缩；说明置于视窗下方，返回按钮位于1092px，与浏览状态的导航分属不同显示序列。详情下方继续使用同一档案面板。

横屏曲线实际尺寸为744×64px，竖屏为952×56px。两者的viewBox分别为`0 0 744 64`与`0 0 952 56`，网格覆盖`0..w`，十二个点的圆心从4均分到`w−4`，半径4px的首尾标记外缘与栏边线相齐且保持完整。画幅切换时更新viewBox并重绘点列和网格。

非render模式支持方向键与按钮切换、Enter读取、Escape返回。手动序列由同一时间轴时钟驱动，同时重建对应声音事件；宿主或控制条seek恢复预设自动演示。render模式关闭自动播放，导出逐帧定位。

### 2.3 乐谱与预加载

乐谱包含低频和声、空气环境、节奏及拨弦，以及启动输入、授权、四向切换、扫描解密、返回和收尾事件。四向提示音高分别为上E6、下C6、左A5、右D6，横向带左右声像；切换后0.46s另有短提示，与文字落定对齐。读取阶段使用玻璃声、双短音、低强度数据音与揭示呼啸。

声音默认关闭，开启后实时播放；渲染通过相同乐谱生成音轨。ready探针实际读到206个事件、`sound:true`、预加载进度1、横竖两个支持画幅。案例没有外部图片、字体或音频资源，预加载使用 `MotionKit.preload([MotionKit.preload.fonts()])` 等待系统字体就绪。

## 五、遗留问题与限制

当前构图的三轮smoke、行为与布局探针、构建检查、横竖预览、56张截图、两段带音轨MP4及ffprobe验收均已完成，没有未完成的必做项。4321服务按要求保留；参考目录只读；没有提交、推送或切换分支。

- 本版以原创SVG三面等轴实体表达轨道和抬起，没有移植真实玻璃透射、AO、景深或三维相机；不是原版物理渲染的逐像素复现。
- 没有360°拆解、收藏、检索、PWA或壁纸工作台；手动操作限方向键/按钮与Enter/Escape，没有直接点档、滚轮和拖拽。这些范围已写入条目。
- 音乐和提示音具备同一乐谱的实时/离线通路；尚未进行真人耳听认证，不能把技术音轨检查等同用户已认可听感。
- seek的10组DOM均一致；竖屏5组PNG均字节一致，横屏2组存在最多1色阶的小量像素差，不把两类证据混为逐字节相同。
