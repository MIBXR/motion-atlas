# Arc UI

来源：`kuratlielia/arc-library`，固定提交 `df3a600fd9ffca85ec8607438b599a4408ab8562`。

组件取自 Web Atlas 的 `arc-ui` 免费素材快照，采用 MIT 许可，原文见本目录 `LICENSE`。`registry/`、`lib/` 和 `types/` 保留上游目录关系；`@/` 指向本目录。

Accordion 提供受控的 `open` 和 `onOpenChange`，用于保留文档目录各组的开合状态。
Combobox 提供 `clearable`，必选来源或样例不显示清除选择按钮。

控件的复制、关闭、代码展开与无障碍提示使用中文。
