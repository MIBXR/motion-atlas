# 使用指南

Motion Atlas 提供完整案例、独立巧思和制作素材。案例与巧思详情中可预览作品、拖动时间轴、查看节拍与参数、复制 Prompt；素材详情中可阅读工作流、作者效果图与原文。

## 预览作品

详情上方的舞台可播放、暂停和全屏；拖动刻度条或点击节拍时间定位，也可跳到前后标记。横竖画幅按钮仅在作品支持多种构图时显示，切换后保留当前时刻，舞台整体等比缩放。

声音默认关闭，点击声音按钮启用；若显示“待启用”，点击舞台或再次点击声音按钮。加载状态显示在舞台周围；地图镜头等待必要瓦片就绪后继续。

操作台可使用键盘、鼠标或触摸输入。真实操作进入手动状态，播放或定位回到自动驾驶。每个作品的具体按键、布局与时长见条目，播放协议与声音接口见[渲染管线](pipeline.md)。

## 从参考到作品

先阅读完整案例的节拍表和能量曲线，判断时间结构是否合适，再用巧思详情中的机制和组合关系选取需要的动作。字段释义见[贡献指南](../CONTRIBUTING.md#条目字段)，阅读顺序见[条目阅读方法](methodology.md)。

复制实现 Prompt 后替换内容、品牌、配色和尺寸，保留需要的时间与动效参数；条目提供视频生成 Prompt 或负向约束时可一并使用。写法见[Prompt 指南](prompting.md)。

需要源码、独立 Demo 或原文快照时，按[Agent 取材说明](agent.md)检索和导出；视频帧序列与音轨导出见[渲染管线](pipeline.md#九逐帧渲染成视频)。每个作品的可调整配置见条目中的迁移指南。

## 在实验室练节奏

1. 选择拍号、BPM、鼓组／木块／电子／机械音色，比较重拍、细分、三连音和摇摆；用打拍测速取得速度。
2. 载入示例或录入打拍，调整首拍偏移和量化强度，交替听 A 原始／B 吸附后的落点，并观察早晚毫秒数。
3. 调缓动、时长与错峰，把起步或最后一个元素落点对到小节重拍，用线性对照和轨迹观察变化。
4. 导出 CSS 变量、MotionKit 乐谱、Prompt 或 WAV。录入事件按秒保存；按新 BPM 生成示例时重新载入。

节拍与吸附的推导见[节奏方法](rhythm.md)。

## 收藏与迁移

案例、巧思与素材收藏共用当前浏览器 `localStorage` 中的 `ma-favorites`。各库导出同一格式的 `motion-atlas-favorites.json`，导入时合并有效条目并去重。

更换浏览器、域名、端口或清理网站数据前导出 JSON，在目标地址导入即可继续使用；收藏保存在当前浏览器。

## 本地使用

需要 Node.js 22+，运行时无需安装项目依赖；截图与渲染需要本机 Edge 或 Chrome，合成 MP4 需要 PATH 中的 ffmpeg。启动命令见[贡献指南](../CONTRIBUTING.md#新增流程)。通过本地服务器访问页面，地图 Demo 的 MapLibre、底图与高程瓦片需要网络。
