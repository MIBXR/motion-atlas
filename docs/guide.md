# 使用指南

Motion Atlas 是一个面向**按时间线播放的影像视频、交互操作台与展示台**的参考库，关心画面在时间里怎么走：节拍、动势、转场、反馈与收尾。

每一条资料都同时给出三样东西：

1. **拆解**：镜头、信息层、文字、事件、声音分轨描述，附节拍表、能量曲线与动效 Token。
2. **Prompt**：可直接复用的实现 Prompt（给代码模型）、视频生成 Prompt（给视频模型）与负向约束。
3. **Demo**：零依赖的 HTML/CSS/JS，改 `config.js` 或文件顶部的 `CONFIG` 就能迁移；按时间播放的Demo 还能逐帧渲染成视频。

## 收录边界

本库收录以时间线为载体的作品：作品掌握节奏，按时间线播放；即使可以交互，也是在时间线上分支。每个时间驱动的 Demo 都能逐帧渲染成视频。

**收录**
- 影像视频：片头、宣传片、旅行影像、数据短片等
- 交互操作台与展示台：带自动驾驶时间轴的终端、档案界面、展会展示
- 能从案例中单独借用的转场、节奏、文字动效、画面构成、信息层、质感、声音与镜头巧思

**不收录**
- 网站与网页应用，包括其中的页面动效和微交互。这类设计收录在 Web Atlas。

**判定**
1. 最终形态是视频，或是带时间轴、按时间线播放的操作台／展示台：收录，即使它运行在浏览器里。
2. 最终形态是网站或网页应用：不收录。
3. 仍难判断时，设想把它逐帧导出为视频。核心价值仍在，收录；价值依赖重排、滚动阅读和观看者自己的节奏，不收录。
4. 同一来源在两种载体上都有价值时，只收录时间线部分，条目本身保持完整。
5. 主题相同、表现形式不同的作品可以分别出现在两个库里，各自是独立条目，互不引用。
6. 画幅不是判据：原作即使是固定画幅，复刻时也可以调整或拓展。各判据冲突时，以“谁掌握时间”为准。例如一个固定画幅、但完全由观看者拖拽操作、没有时间线的网页光照演示，不属于本库。

## 两种载体

- **影像视频（video）**：最终产物是一段视频。所有元素写在时间轴上，`render(t)` 只依赖时间 `t`，可以拖动刻度、跳到节拍、逐帧导出。代表：地图巡礼。
- **交互操作台（console）**：用户在界面上做选择、锁定、确认。重点是**输入 → 反馈 → 余波 → 回程**这条链，以及空闲时界面如何“呼吸”。代表：莱茵生命档案终端。

地图巡礼属于影像视频，档案终端属于交互操作台。两者都可以按时间轴播放与导出视频。

## 画幅、声音与加载

地图巡礼与档案终端分别提供横屏 **1920×1080** 和竖屏 **1080×1920** 两套固定构图。舞台整体等比缩放到详情页的黑色容器内；工具栏切换画幅时保持当前时刻，刻度条与播放 / 暂停按钮位于舞台下方。桌面上舞台随视口高度适配，完整显示画面与刻度条。

两者的配乐和事件音都由 MotionKit 的 WebAudio 引擎合成，默认静音，可用详情页声音开关开启；浏览器若显示“待启用”，点击舞台或再次点击声音按钮。乐谱与画面共用时间轴，渲染时加 `--audio` 可输出音轨。必要资源先预加载，详情页显示进度；地图巡礼按镜头计划渐进缓冲瓦片，缓冲不足时保留当前画面并等待。

- **地图巡礼**：60 秒的关西三日路线，从上海飞抵关西机场，再到京都伏见稻荷、鸭川、奈良公园和大阪道顿堀；照片卡片与明信片均为程序绘制的原创场景。
- **档案终端**：77.6 秒的莱茵生命档案界面，五类各八份记录。上下翻档、左右切列均首尾循环，并记住各列选择；使用方向键或按钮、Enter 读取、Escape 返回。拖动刻度条会恢复预设演示。

档案终端的5个巧思使用自适应布局，不显示横竖画幅切换按钮。声音通过共享运行时控制。

## 怎么用这份资料

### 想做一支视频

1. 在案例库按“影像视频”筛选，挑一个节奏接近的案例，先看**节拍表**和**能量曲线**，确认起伏结构是你要的。
2. 复制“视频生成 Prompt”，把主题、地点、配色换成你的内容；保留时长、节拍与镜头语言部分。
3. 如果要用代码出片：复制 Demo 文件夹，改 `config.js` 里的文案、颜色、时刻表，然后用 `node scripts/render.mjs <demo>/index.html --fps 30` 渲染成帧序列（装有 ffmpeg 时自动合成 MP4）。详见 [渲染管线](pipeline.md)。

### 想做一个可操作的界面

1. 在案例库按“交互操作台”筛选，读“交互”一栏：每个输入对应的反馈与时长。
2. 去巧思库挑骨架（foundation）、支撑（support）与点睛（accent）三类巧思组合，一般 **1 个骨架 + 2–4 个支撑 + 1–2 个点睛** 就够了，更多会互相抢戏。
3. 把巧思的实现 Prompt 拼进你的需求描述里，或直接把巧思 Demo 的 `CONFIG` 块与核心函数搬进项目。

### 想调手感

去 [节奏实验室](../lab.html)，按四步练习：

1. **感受节拍**：选拍号、BPM、鼓组 / 木块 / 电子 / 机械音色，听重拍、拍与细分，比较三连音和摇摆；可用打拍测速确定速度。
2. **理解吸附**：载入示例或打拍录入事件，调首拍偏移和量化强度，交替听 A 原始 / B 吸附后；时间线与早晚毫秒数同步显示变化。
3. **曲线 × 时长 × 拍子**：拖缓动曲线，调时长和错峰，把起步或最后一个元素的落点对到小节重拍，配合线性对照和轨迹观察。
4. **导出**：复制 CSS 变量、MotionKit 乐谱代码或 Prompt，或将当前循环导出为 WAV。事件按秒保存，改 BPM 不会自动缩放已录事件；需要按新速度生成示例时重新载入。

方法论见 [节奏方法](rhythm.md)。

## 本地运行

需要 Node.js 22 以上，无需安装依赖；截图与渲染需要本机 Edge 或 Chrome，合成 MP4 另需 PATH 上的 ffmpeg。

```bash
node scripts/serve.mjs --port 4321
```

然后打开 `http://localhost:4321/`。直接双击 HTML 也能看大部分页面，但地图 Demo 与刻度条需要通过本地服务器访问。

常用命令：

| 命令 | 作用 |
| --- | --- |
| `node scripts/build.mjs` | 同步 kit 副本，生成站点数据、Prompt 文档与 Agent 资料包 |
| `node scripts/capture.mjs` | 按条目里的 `previewAt` 重新截取预览图 |
| `node scripts/render.mjs <url或路径>` | 逐帧渲染按时间播放的Demo |
| `node scripts/atlas.mjs search <关键词>` | 命令行检索；`show`、`export` 见 [Agent 工作流](../agent.html) |

## 目录

```text
entries/cases/*.json      案例条目（唯一内容源）
entries/patterns/*.json   巧思条目
demos/cases/<id>/         案例 Demo：index.html、style.css、script.js、config.js、motion-kit.js
demos/patterns/<id>/      巧思 Demo：单文件 index.html + motion-kit.js
kit/motion-kit.js         共享运行时（Demo 内为同步副本）
docs/                     指南与使用方法
prompts/                  由条目生成的 Prompt 文档
agent/                    由条目生成的 Agent 索引与资料包
data/                     由条目生成的站点数据
previews/                 Demo 实际截图
scripts/                  服务器、构建、检查、截图、渲染与 CLI
```

`prompts/`、`agent/`、`data/` 都是生成物，请改 `entries/` 后运行构建，不要手改。
