# 节奏方法：曲线、时长、错峰、拍子

“有动感”“有韵律”听起来是感觉，落到实现里其实是四个数和一张表。本篇把本库所有案例共用的节奏方法写下来，[节奏实验室](../lab.html) 可以直接调这些数。

## 一、四个数

### 1. 缓动曲线：决定“性格”

本库的命名 Token 与 `kit/motion-kit.js` 中 `MotionKit.ease` 一一对应：

| Token | cubic-bezier | 性格 | 典型用途 |
| --- | --- | --- | --- |
| `snap` | `0.2, 0.9, 0.1, 1` | 机械吸附：一下冲到位，硬停 | 操作台选中、光标跳格、HUD 读数归位 |
| `glide` | `0.25, 0.1, 0.25, 1` | 平滑滑行 | 镜头推移、面板平移、长距离位移 |
| `emphasized` | `0.2, 0, 0, 1` | 强调进入：起步干脆、尾部很长 | 标题入场、卡片展开、重要信息出现 |
| `exit` | `0.4, 0, 1, 1` | 加速离场 | 元素退出、转场遮罩收走 |
| `anticipate` | `0.36, 0, 0.66, -0.56` | 先回拉再出发 | 蓄力、抽卡前的停顿、冲击前的后撤 |

经验规则：

- **进入用减速（ease-out），离开用加速（ease-in）**。离场时长约为进场的 60–75%。
- 同一屏幕里的主运动只用一种主曲线，其他曲线为它服务。P5 式界面几乎所有东西都是 `snap` + 极短时长；水墨长卷几乎都是 `glide` + 长时长。曲线混用是“没有风格”的最常见原因。
- 回弹（overshoot / outBack）只用于点睛：奖章落定、印章盖下。用在常驻元素上会显得廉价。

### 2. 时长：决定“重量”

| 档位 | 时长 | 用于 |
| --- | --- | --- |
| 瞬时 | 60–120ms | 按下反馈、闪白、命中帧 |
| 短 | 150–250ms | 选中切换、小面板、字符解码的每一跳 |
| 中 | 300–500ms | 卡片展开、标题入场、转场遮罩 |
| 长 | 600–1200ms | 镜头推进、地图飞行、整屏揭示 |
| 场景 | 2–6s | 一个镜头 / 一个段落的停留 |

尺寸越大、移动距离越远，时长越长；但操作台里**用户触发的反馈不要超过 300ms 才开始响应**，可以先给 80ms 的即时反馈，再接长动画。

### 3. 错峰（stagger）：决定“层次”

一组元素依次出现时的间隔。总时长 = 时长 + 错峰 ×（数量 − 1）。

- 错峰 ≈ 时长的 10–20%：看起来是“一组”，有方向感。
- 错峰 ≈ 时长的 50% 以上：看起来是“一个接一个”，适合打字、逐字冲击。
- 元素很多时（> 12 个），不要线性错峰，改用按距离错峰（从焦点向外扩散），或给总时长封顶（例如 600ms 内全部出现）。

### 4. 拍子：决定“律动”

视频与带音乐的界面以 BPM 为时间单位。1 拍 = 60 / BPM 秒；120 BPM 时 1 拍 = 500ms，1 小节（4 拍）= 2 秒。

- 先写**拍号表**，再写秒数：`{ beat: 8, text: 'WE MOVE', style: 'slam', hold: 2 }`。改 BPM 时整支片子自动跟着变。
- 关键事件（切镜、冲击字、闪白）吸附到拍点；次要事件吸附到半拍或十六分；粒子与呼吸动画不吸附，保持自由。
- 小节第一拍放最重的事件；第 2、4 拍（军鼓拍）适合闪光、斜条纹；反拍（+0.5 拍）适合小幅回弹。
- `MotionKit.beats(bpm, offset)` 提供 `at(beat)`、`beatOf(t)`、`pulse(t, decay)`、`quantize(t, div)`。

### 5. 吸附：网格、偏移、强度与摇摆

把事件“吸附”到拍上之前，先决定吸到哪种网格、吸多少：

| 参数 | 含义 | 选法 |
| --- | --- | --- |
| 网格（细分） | 每拍切成几格：拍 / 半拍 / 三连音 / 十六分 | 网格要和素材的节奏一致。网格太粗会把**切分**（落在反拍上的事件）拉回正拍，节奏变平；三连音素材用十六分或半拍网格会被吸得不均匀，甚至两下挤到同一点 |
| 首拍偏移 | 第一个重拍在素材里的位置（毫秒） | 音乐通常不是从第 0 帧开始。偏移错了，所有事件都会整齐地吸错半拍 |
| 量化强度 | 0–100%：每个事件朝网格点移动的比例 | 100% 完全对齐、最“机械”；50–80% 收紧明显的拖拍，又保留一点人手的松动 |
| 摇摆（swing） | 把成对格子的后一格推迟，100% = 三连音 shuffle（长短比 2:1） | 只作用于半拍、十六分网格。爵士、嘻哈、Lo-fi 的律动在摇摆里；用直拍网格吸附会把它拉直 |

拍号决定重音的位置：4/4 是“强—弱—次强—弱”，3/4 是“强—弱—弱”；6/8、7/8 按八分音符计拍，分别按 3+3、2+2+3 分组，每组第一拍是次强拍。重的动作放小节重拍，次要强调放次强拍。

### 6. 在节奏实验室里练

[节奏实验室](../lab.html) 按这个顺序安排，声音和画面都由同一个音乐时钟驱动：

1. **感受节拍**：节拍器分小节重拍、拍、细分三级音色与音量，改速度、拍号、细分、摇摆在下一个格子立刻生效；可以打拍测速。
2. **理解吸附**：一圈 1–4 小节的时间线，A 道是原始事件、B 道是吸附后，箭头标出移动量；“A/B 交替”一圈放原始、一圈放吸附后。示例里有拖拍、切分、三连音、摇摆和真实剪辑点；也可以在打拍板上跟着节拍器敲一圈，录下自己的时刻再吸附，并看到每一下早 / 晚多少毫秒。
3. **曲线 × 时长 × 拍子**：预览每小节重播一次，可选“落点踩重拍”或“起步踩重拍”，起步有呼啸、落定有提示音；时长与错峰可以一键设为几分之一拍或网格步长。
4. **导出**：CSS 变量、MotionKit 代码（含节拍器与事件的乐谱）、Prompt 片段，以及用同一套合成音色离线渲染的 WAV。

## 二、能量曲线

每个案例都有一条 0–1 的能量曲线（`energy`），把整支片子按等间隔采样，描述“此刻画面有多激动”。它不是动画参数，而是**设计前的草图**：

- 好的曲线有**起伏**：起—承—转—合，或“慢—快—停—快—停”。一直在高位会疲劳，一直在低位会无聊。
- 高潮前要有**低谷或停顿**。P5 式战斗的 HOLD UP、抽卡的升级前停顿、节拍 MV 的 Build 到 Drop，都是先把能量压下来再释放。
- 结尾要**回落**，给观众时间读结果：结算板、尾卡、统计数字。

画法：先用 8–16 个点手画曲线，再给每段配“能量对应的手段”——低能量用留白、慢镜头、单一元素；高能量用密集节拍、色块轮换、震动、多层叠加。

## 三、分层

把画面拆成独立的轨道，每条轨道各自有节奏，叠起来才有层次：

| 轨道 | 内容 | 节奏特征 |
| --- | --- | --- |
| CAM 镜头 | 推拉摇移、缩放脉冲、震动 | 慢、连续；在重拍上加脉冲 |
| HUD 信息层 | 时间码、坐标、状态、进度 | 常驻、低调；读数变化用 `snap` |
| TYPE 文字 | 标题、字幕、标签 | 在段落开头出现，跟拍或跟语义 |
| FX 特效 | 闪白、扫描线、遮罩、粒子 | 短促，压在重拍上 |
| SFX 声音 | 点击、冲击、环境 | 与 FX 同步；默认关闭，由用户开启 |

原则：**同一时刻最多一条轨道当主角**。镜头在大幅运动时，文字保持静止；文字冲击时，镜头只做小脉冲。

## 四、交互的节奏

操作台的节奏由用户驱动，但同样可以设计：

1. **输入**：按下瞬间 60–120ms 给形变或亮度反馈。
2. **反馈**：结果出现，用主曲线，150–300ms。
3. **余波**：涟漪、读数滚动、关联元素轻微跟随，延迟 40–120ms 出现。
4. **回程**：状态稳定后进入空闲呼吸（2–4s 周期，幅度 ≤ 2%）。

长按确认（hold-confirm）、蓄力释放（charge-release）这类巧思把“输入”本身拉长成一段节奏，适合不可撤销的操作。

本库的交互 Demo 还有一条**自动驾驶时间轴**：没有用户输入时按预设事件表演示自己；一旦有真实输入就切换到实时时钟；外部 seek 或播放时再回到自动驾驶。这样同一份代码既能被操作，也能被录成视频。

## 五、减少动态

所有 Demo 都遵守 `prefers-reduced-motion`：

- 位移、缩放、旋转、震动 → 改为透明度淡入或直接出现。
- 闪烁、频闪（> 3 次/秒）→ 去掉。
- 自动播放的长动画 → 停在一个能读懂的关键帧，保留手动播放。
- 节拍信息不要只靠运动传达：同时用颜色、文字或计数显示。
