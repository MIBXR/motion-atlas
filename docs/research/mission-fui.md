# 任务指挥台：设计说明

- 类型：原创设计语言（2026-10-14）
- 目标：把影视 FUI 的“持续工作感”和“状态一致性”做成可复用机制。

## 两层节奏

| 层 | 周期 | 内容 |
| --- | --- | --- |
| 持续层 | 4s（扫描）/ 每帧（波形）/ 0.6s（打字） | 雷达、示波器、系统条、日志 |
| 事件层 | 3–4s | 锁定、告警升级、恢复 |

持续层让画面永远“在呼吸”；事件层负责叙事。两者叠加时，事件要比持续层更“硬”（snap、阶梯、方波闪烁），才能被注意到。

## 状态即主题

所有组件只读 `--main / --dim / --bg / --panel` 四个变量与同一个闪烁时钟。切换状态 = 插值四个颜色 + 换一个闪烁频率。新增状态只需在 `config.js → states` 加一行。

## 验证记录

- 2026-10-14：Edge 无头 1600×900 截取 8 个时刻（展开、扫描、锁定中、已锁定、CAUTION、ALERT、恢复）；降低了余辉扇区的角宽与不透明度。
- Canvas 文字按缩放换算字号；窄屏改为纵向堆叠并允许滚动。
