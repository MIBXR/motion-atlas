## 为什么值得收录

这个项目把一段几十秒的宣传影像“反推”成可以操作的系统，并且对每一个动作都追问了三件事：从哪里来（方向）、留下什么（余波）、怎么回去（回程）。这正是“交互操作台 / 展示台”最需要学习的部分——不是视觉风格，而是让每次输入都有质量。

## 设计语言

| 维度 | 观察 |
| --- | --- |
| 色彩 | 暖灰白底（`#eae5e1`）、近黑文字、暖杏金/铜色为唯一信号；亮暗两套配色，卡片依次变色。 |
| 字体 | 用户指定 MiSans；品牌三行精确到字距和每个字符的位置（第一行 44px/2.5px，第二行 19px/600，第三行 35px）。 |
| 版式 | 品牌左上、系统右上、信息中右、计数左下、导航中下、署名右下、状态页脚。阵列铺满并溢出画面，用浅色遮罩在上下与右侧淡出。 |
| 质感 | 透明档案盒：磨砂盖板、基板、内部光学腔、双环、螺钉、标签与刻线；物理透射材质。 |
| 声音 | 原片三个 38ms 逐字短音轮替、玻璃交互音（短起音、不等间隔共鸣、迅速衰减）、三轨循环配乐，音乐与音效可分别开关。 |

## 关键机制与参数（文档原值）

- **启动**：以原片 25fps 逐帧复核；逐字输入、停顿、清空、闪切固定到帧点；标志从右上弧线开始、绕左环再补全右环；权限段黑白双环从画面外收拢、反向内弧、橙色节点、四帧缩放跳变；欢迎段黑白闪切、公司名黑底横扫、INTERNAL DATABASE 闪现；最后缩小、失焦、带轻微青色过渡进入白场。
- **阵列**：五类 × 每类八份 = 40 份；上下翻阅、左右切列均循环；切回某列保留上次选择；选中抬起与阵列波浪同时开始；升降为保留速度的临界阻尼（速率 4.2），快速重新选中时接续运动。
- **滚动文字**：编号与标题共享 460ms，固定向上滚，标题模糊 0.2；连续输入只显示可见过渡与最新目标。
- **呼吸**：停止 2.5 秒后渐入；8 秒与 13 秒周期叠加；最大单向位移约卡片高度 2.8%；相邻错相；切换、进入详情或减少动态时渐退。
- **详情过渡**：详情层 180ms 进出；弹窗 300ms 入 / 200ms 出，位移 12px / 8px，可从中途反向；页签正文 150ms 淡入，下划线 180ms 连续移动。
- **解密**：对角线合拢、保持、收束；盖板自上而下由磨砂变清晰；正文遮挡条随之退开。

## Demo 的取舍

| 原项目 | Demo | 说明 |
| --- | --- | --- |
| Three.js 透射玻璃模型、Blender 制作 | CSS 3D 三面方块 | 零依赖、易迁移；没有透射与阴影 |
| 镜头沿原片关键帧转向与推近 | 世界整体平移、缩放、俯仰插值 | 本地拟合 |
| 9 列 × 32 行循环阵列 | 5 列 × 16 块 | 足以表现波浪与选择 |
| 原片逐字音、配乐 | WebAudio 合成短音（默认静音） | 不分发原片音频 |
| 360° 拆解查看器、画质设置、PWA、壁纸工作台 | 未实现 | 超出机制学习范围 |
| 品牌与档案正文 | 原创 LUMEN LAB 与虚构档案 | 不使用原作名称与标志 |

所有状态写成“按键事件序列在时刻 t 的解析函数”：抬起是临界阻尼阶跃的闭式解，余波是衰减正弦的叠加，呼吸是两个正弦的和。这让同一套代码既能被刻度条拖动、逐帧渲染，也能在真实按键后用实时时钟继续运行。

## 验证记录

- 2026-10-14：Edge 无头模式 1600×900 下截取 1.2–22.5 秒共 12 帧，覆盖启动五段、阵列入场、切列、翻阅、读取解密三个阶段与返回。
- 发现并修复：`preserve-3d` 容器设置 `opacity < 1` 会把 3D 面压平（详情返回后档案块只剩顶面）→ 改为把透明度加在每个面上；阵列初版偏小 → 放大并让阵列从画面边缘溢出；选中块位于后排被遮罩 → 改到中排。
- 未验证：真实移动设备上的 CSS 3D 性能；屏幕阅读器对实时交互状态的播报完整性。
