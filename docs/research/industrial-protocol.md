# 终末地 · 集成工业协议

本案例复刻《明日方舟：终末地》集成工业系统的界面与交互，以60秒横、竖两套构图演示工业模式HUD、蓝图放置与建造、配件机生产与收取、干员升级和蓝图分享。地面、设施和物品为原创工业素材，中央人物按女性管理员外观文本生成，均使用内置 `image_gen.imagegen` 生成的风格化位图；界面参考游戏，未使用游戏美术素材，也未向生图工具提供官方美术作为输入。

界面观察来自本地保存的官方实机视频、抽帧和联系表；制作参数来自用户的T7设计规格。本文区分参考画面中可见的界面事实与本案例采用的时序、尺寸及数值，不把设计参数写成原游戏动效实测。

## 界面观察

### 标题与工业HUD

标题为黑底白色 `ENDFIELD` 字标，上方有小号 `ARKNIGHTS`，右侧为“终末地”方块。探索和工业模式使用左上标签切换，工业模式显示顶部资源计数胶囊和底部物品栏；场景设施使用图标与中文名称标牌。右下圆形按钮、胶囊与黄色选中态贯穿操作层。

### 放置蓝图

03号视频00:43.350可见左上 `//放置蓝图` 和品牌细彩条；俯视草地上有带三角形结构的大型协议核心，四边带黄色三角箭头。蓝图设备与连接带为半透明蓝色虚影；已建设施为深色方块，四角有黄色角标，中心为图标和名称缩写，待机时头顶有蓝色 `Zz`。传送带为橙黄色。顶部资源显示 `2065/3460`、`100%`；右侧为移动镜头、缩放、旋转、确认和取消的键鼠提示。

### 配件机面板

03号视频00:45.583可见半透明白灰设备窗口叠在俯视地图上。左上设备图标与“配件机”“耗电功率值: 20”同列，下方为开/关切换。左栏背包为物品格，容量 `24/35`，数量置于格角，底部色条区分稀有度，下面是仓库投放区。右栏为设备示意图、输入输出格、生产时间和配方条，黄色“全部收取”胶囊在右下；面板底部有进度与“生产中”状态。

### 干员界面

01号视频01:39–02:46的干员界面使用浅灰底，中央人物，顶部一排头像页签。左侧信息包括名字、星级、属性方块和一排圆形技能。右侧亮黄色斜带从右上切入，带内竖排巨大 `ENDFIELD` 描边字，叠加大号 `20` 和 `LEVEL/40`。

### 蓝图纸与分享弹窗

研究笔记中的蓝图俯视/分享观察包括浅灰网格纸、白色设备、深色圆形图标、点状黄色传送带与带箭头的深色分流节点。详情为深灰面板与设施缩略图格，右下有白色字标和彩条。分享类弹窗使用横贯画面的白色条带，压暗背景，居中标题、浅灰输入框和复制图标；深灰取消、亮黄确认均为胶囊，左端带一条细横线。

## 本案例的表达与参数

全组位图采用平面着色、简化形状、清晰轮廓和白灰炭黑/柠檬黄点缀；中央人物为短黑发、护目镜、灰色技术外套的女性管理员，生成输入只使用文本。

- 版式、交互、动效、配色及字体风格参考真实游戏。15张风格化位图用于地面、设施实体、S3六类物品和S4中央人物，均由内置 `image_gen.imagegen` 按文本提示生成；未输入游戏截图、官方角色立绘、图标或logo图片。功能SVG、设施状态与机械动效叠层、蓝图虚影、蓝图纸、人物背景浅剪影与头像保留代码绘制。
- FFmpeg仅做尺寸归一化及PNG/WebP格式转换，保留画面内容与Alpha；地面为2048×2048无损WebP，7张设施为512×512 RGBA PNG，6张物品为128×128 RGBA PNG，人物为1024×1536 RGBA PNG。人物呼吸采用4秒周期、缩放1±0.01及倾斜±1°。
- 字体使用Google Fonts的OFL字体Barlow Semi Condensed 400/600/700（字标700斜体）与Noto Sans SC 400/500/700，经 `MotionKit.preload` 加载。不使用官方字体文件。
- 两套固定舞台为1920×1080、1080×1920；竖屏使用触控点、右下操作圆钮、底部设备弹层与干员卡片，以及下方蓝图详情。
- S4横屏黄带多边形为(1440,0)、(1920,0)、(1920,1080)、(1640,1080)；等级块左x1500，220px数字框顶250，LEVEL/40顶500，经验条(1500,532)260×8，按钮(1500,568)260×64，提示条中心(960,120)。160px旋转描边字的目标外框为(1780,80)120×920。
- S4竖屏人物高900，水平中心x400、头顶y330；黄带为(720,0)、(1080,0)、(1080,1220)、(900,1220)。等级块左x720，200px数字框顶800，LEVEL/40顶1010，经验条(720,1046)宽300，按钮(720,1080)300×80；提示条中心(540,200)，信息卡(40,1240)1000×640。150px旋转描边字的目标外框为(950,110)120×680。LEVEL/40不得与人物相交，旋转字必须完整显示。
- 地面以原创草地贴图平铺，Canvas保留网格、边界遮罩、传送带和运送物料。设施实体使用风格化位图，叠加黄色角标、进出料三角、蓝/绿状态灯及炉口、齿轮、双辊、电弧等代码动效；蓝图虚影保留对应内部线框。传送带宽40px、两侧深边各4px，白色V箭头以80px/s移动，物料带2px深色描边。
- 三设备蓝图依次为配件机A 128、传送带64、粉碎机128、传送带64、仓储箱128，总长512px；一格为64px。三台分别于14.6/14.9/15.2s成形，产线连接协议核心 → A → 粉碎机 → 仓储箱 → B。
- 数值、配方和时序是本案例的设计参数：资源2065→2214，生产输入9→7、输出0→2，收取背包20→22；等级20→21，攻击342→358、生命2341→2420、防御326→335。它们不是游戏规则指南。
- 音效由kit已有音色合成，13.0s旋转事件为 `click`、增益0.9；不使用官方音乐或音效。`motion:ready` 要求 `sound:true`，全长导出带音轨。
- 画面由 `render(t)` 决定，位图经 `MotionKit.preload` 加载，程序动效随时间确定。`prefers-reduced-motion` 仅将镜头推拉与斜带扫屏替换为淡入淡出，其余时序照常。

- 工作中的粉碎机双辊分别以1.2秒一圈正反转，待机静止。
- 建造标题与任务背后使用左深右透明的渐变衬底：横屏(0,96)560×124，竖屏按舞台比例换算为(0,170.667)315×220.444。右侧按键提示每行使用深色胶囊，内边距6px 12px、圆角6，右缘距舞台48px。
- 条目声明renderer:gpu。横屏以Zz表示待机；竖屏隐藏Zz，以蓝色状态灯和设施图像0.7透明度表示待机。精炼炉/配件机B/供电桩在19.0/19.4/19.8秒开始0.3秒蓝绿灯色及设施图像0.7→1插值，外圈旋转细环出现。

- 静态地面贴图及设施位图采用保留层；完整带体按画幅离屏缓存，静止flow不重画。动态帧只更新变化属性，光标路径不读取布局。

- 世界坐标中种植机中心为(300,900)，供电桩中心为(1560,520)，横竖共享；其他设施位置保持设计参数。
- 竖屏地图名牌默认隐藏。配件机A、粉碎机、仓储箱在14.6/14.9/15.2秒成形开始时，名牌0.2秒淡入、满显1.2秒、0.3秒淡出；名牌位于设施左侧，右缘距设施左缘12px，垂直居中。横屏名牌持续显示于设施下方。
