# 节拍动态字幕：设计说明

- 类型：原创设计语言（2026-10-14）
- 目标：示范“韵律感”如何被工程化——把视觉事件全部写成拍号，并让不同层级的变化使用不同的音乐频率。

## 频率分层

| 层 | 频率 | 表现 |
| --- | --- | --- |
| 文字 | 每拍（Build 段八分音符） | 拍入 / 遮罩上升 / 网格点亮 |
| 镜头 | 每拍（底鼓） | 缩放脉冲，Drop 加震动 |
| 闪光 | 第 2、4 拍（军鼓） | 斜条纹 difference 闪 |
| 颜色 | 每 2 小节（段落） | 新色块从左擦入；Drop 每拍换色 |
| 版式 | 每段 | 中心 → 网格 → 散点 → 铺满 |

层级越高，变化越慢；这样画面始终有律动，但不会“所有东西一起抖”。

## 音画同步

浏览器的 requestAnimationFrame 每帧约 16ms，且会抖动；如果在“到点那一帧”才播放声音，听感会拖拍。Demo 把未来 120ms 内的音符提前交给 AudioContext，以精确的 `delay` 播放；拖动刻度条后重置调度游标。接真实歌曲时，用 `audio.currentTime` 作为 t，并测出第一拍的偏移量。

## 验证记录

- 2026-10-14：Edge 无头 1600×900 截取 12 个时刻，覆盖倒数、拍入、中文遮罩、堆叠网格、Build、Drop、Outro；把结尾卡提前到第 44 拍以消除 2.5 秒空白。
- 声音调度通过代码审查与本地试听验证事件顺序；未在多设备上测量音画延迟。
