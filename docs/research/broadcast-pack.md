# 赛事转播图形包：设计说明

- 类型：原创设计语言（2026-10-14）
- 目标：给“视频生成 / 直播包装”提供一套可直接迁移的图形语法，并示范如何把图形编排写成节拍表。

## 设计原则

1. **一次只讲一件事**：常驻层（角标、新闻条）永远在边缘；事件层（人物条、数据、得分、冠军）一次只出现一个，彼此间隔至少 1 拍。
2. **同一套入场语法**：颜色先行（色条/色带）→ 承载面（底板）→ 信息（文字/数字）。离场倒序，并且更快。
3. **节拍是唯一的时间单位**：所有出入场写成拍号，BPM 改变时整体同步；转场 2 拍、人物条停留 6–7 拍、数据每半拍一行。
4. **颜色有角色**：主队/系统、客队、状态（直播/回放）、正文，各用一种颜色，不混用。
5. **转场遮住硬切**：场景切换发生在色带完全遮住画面的那一刻，观众只看到品牌。

## 节拍表（120 BPM）

| 拍 | 秒 | 元素 |
| --- | --- | --- |
| 0 | 0.0 | 开场色带 + 标志 |
| 4 | 2.0 | 比分角标 |
| 8–15 | 4.0–7.5 | 下三分之一 |
| 16–23 | 8.0–11.5 | 数据对比 |
| 24 | 12.0 | 得分强调 |
| 28–36 | 14.0–18.0 | 回放（色带进出） |
| 37 | 18.5 | 滚动新闻 |
| 42 | 21.0 | 冠军卡 |
| 46 | 23.0 | 结尾色带 |

## 迁移提示

- 接真实节目时，把 `beats` 改成节目流程中的实际时刻（可用 `quantize` 吸附到最近的拍）。
- 下三分之一与角标的尺寸按 1920×1080 设计，窄屏自动改为通栏。

## 验证记录

- 2026-10-14：Edge 无头 1600×900 截取 12 个时刻 + 回放单帧；补充了回放段的慢动作轨迹与时间码；拍点指示灯移到右下避免与回放标签重叠。
