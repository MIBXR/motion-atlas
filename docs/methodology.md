# 条目阅读方法

案例帮助理解完整作品怎样组织时间，巧思帮助借用一个机制，素材帮助取得制作资源。完整字段定义见[贡献指南](../CONTRIBUTING.md#条目字段)。

## 阅读案例

先播放一遍，再回到节拍表，逐段观察进入、停留与退出。把能量曲线与镜头、信息层、文字和声音的变化放在一起看，确认同一时刻的主角。

接着阅读构成、画面分层和画面细节，在相应时刻定位。交互与状态说明操作如何改变画面；迁移指南指出可调整的内容和参数；关联巧思将局部动作接回完整作品。

## 阅读巧思

从触发与结果辨认动作的起止，再用机制和参数理解中间过程。重复播放同一小段，观察时长、缓动、错峰、幅度与声音落点之间的关系。

组合时先确定骨架，再添加支撑和点睛，阅读各条目的搭配与冲突条件。可访问性部分说明减少动态和键盘操作方式，所属案例入口提供完整上下文。

## 阅读素材

先看详情中的工作流和适用范围，再读[素材说明](materials/README.md)与主文档。作者画廊用于理解输出形式，实际制作按照原文完成。素材详情和资料包提供对应的版本与许可入口。

具体操作见[使用指南](guide.md)，节拍与曲线见[节奏方法](rhythm.md)，实现指令见[Prompt 写法](prompting.md)，时间与声音协议见[渲染管线](pipeline.md)。
