# motion-showreel 使用说明

从[素材详情](../../materials.html#material/motion-showreel)阅读工作流，再打开[主文档](../../demos/materials/motion-showreel/SKILL.md)开始制作。把需求、分镜与声音安排放在同一份制作简报里，预览时同时听声音、看镜头切换，再决定需要调整哪一段。

阅读原文时，遇到时间线或声音安排的疑问，沿主文档指向的参考资料继续读；准备复用一个示例时，连同示例依赖的模板与资源一起取得。[中文原文说明](../../demos/materials/motion-showreel/README.zh-CN.md)提供另一条阅读入口。

需要理解如何把制作成果放入本库时，打开详情中的关联案例，在可运行 Demo 里拖动到同一段，结合案例的节拍和配置观察修改入口。独立取得全部原文的方法见[Agent 取材说明](../agent.md)。
