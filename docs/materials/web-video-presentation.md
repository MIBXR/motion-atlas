# web-video-presentation 使用说明

先在[素材详情](../../materials.html#material/web-video-presentation)查看工作流与主题画廊，再打开[主文档](../../demos/materials/web-video-presentation/SKILL.md)。阅读时把原文稿、大纲和演示页面对应起来：一个口播节拍应能指出页面里哪一步发生了变化。

做第一章时，先用真实内容确认文字密度、素材和主题，再将确认后的排版沿用到其他章节。预览时从头推进一遍，检查每一步的阅读停留是否适合要说的话；录屏前把画面推进方式与口播方式一起确定。

[中文原文说明](../../demos/materials/web-video-presentation/README.zh-CN.md)可配合主文档阅读；章节示例、模板和主题沿原文中的相对链接取得。独立取得全部原文的方法见[Agent 取材说明](../agent.md)。
