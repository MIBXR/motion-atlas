# 蝶の舞う庭 · 曲式赏析滚动总谱

魔芋苏打的[「曲式赏析/少女歌剧」蝶の舞う庭](https://www.bilibili.com/video/BV15xn868EoM/)只用两分钟，把剧场版配乐《蝶の舞う庭》前 57 小节讲清楚，视频本身也很有《少女歌剧》的味道。原曲长 401 秒，视频解析的是开头约 115 秒。

## 声音怎么变成画面

全片只有一条时间规则：总谱以 190px/s 向左匀速滚动，音符跨过 x=880 的播放头时发声。小节长短变化不用改速度，音符间距自然变化，所以观众看到的疏密就是音乐的疏密。

音符有三种状态：未来是浅色，发声时变实变粗，过去后留在中间的灰度。同一行里，音高只造成不到一像素一个半音的轻微偏移，整张谱读起来是配器的织体，具体音高交给动机标注。

## 少女歌剧感从哪里来

这部片把“少女歌剧感”落在了可以指认的地方：

- **动机 7135**：导音、主音、三音、五音组成的四音“呼唤”，九次入场全部用括号和数字标出，底部九个图标记录它在乐器间的传递。
- **戏单结构**：曲子被写成序幕、第一場到第四場和間奏，调名用日文伊吕波音名。一首配乐因此读起来像一出戏的节目单。
- **红白反色**：白底是常态，转调和全奏时整个画面翻成 `#e80827` 的红底，配上压在总谱上的巨型场次标题。颜色的变化跟着音乐结构走。
- **右侧红栏**：竖排曲名、官方标志和作曲署名始终固定，像舞台侧幕。
- **调性路线**：F→D→B♭→A→E 的下行路线在片尾画成梯子，把全曲收束成一张图。

## 怎么改

换一首曲子时，重做 `film/data/notes.json` 和 `film/data/timeline.json`，再调整 `ROWS`。逐帧提取脚本和原始测量在 `source/`，需要时可沿用。
