HOW A CASE IS BUILT

一个案例怎么拆

  1. 01

    逐帧观察

    逐帧看画面，记下每个转场、每层信息出现和消失的时刻。

  2. 02

    拆成轨道

    镜头、信息层、文字、事件、声音各一条轨道，写成节拍表与能量曲线。

  3. 03

    抽出巧思

    每个能复用的手法单独成条：怎么触发、什么效果、参数多少、能和谁搭配。

  4. 04

    Prompt + Demo

    实现 Prompt、视频生成 Prompt 和负向约束，配一份改配置就能复用的 Demo。

  5. 05

    渲染与迁移

    同一份代码可以实时播放、拖动定位，也能逐帧导出成视频。
