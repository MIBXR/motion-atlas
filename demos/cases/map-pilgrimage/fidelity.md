# 地图巡礼复刻对照

作品来源见[条目 JSON](../../../entries/cases/map-pilgrimage.json)，原作观察见[研究](../../../docs/cases/map-pilgrimage.md)。参考为用户提供的 151.21 秒、1920×1080 成片。

## 对照结论

现有逐帧研究记录了原片的地图底座、四角 HUD、昼夜翻转、路线描画、章节、回忆、分屏与警示机制；当前代码实现了这些机制。当前作品为 60 秒关西三日路线，时长、路线、文字、素材与声音均与原片不同，未达到 1:1。现有资料没有同视口、同状态的原片与本地并排验收结论。

## 差异与原因

| 范围 | 原作与当前作品 | 原因 |
| --- | --- | --- |
| 时长、日序与路线 | 原作约 151.21 秒、七日，首尔经关西至东京；当前为 60 秒、三日，上海经关西、京都、奈良至大阪。 | 研究记录以原片的日本旅行与地图结构为取景依据；缩短时长、日序及改写起终点的原因未记录。 |
| 标题、正文与章节 | 原作「聖地巡礼」、作品主题、人物标签与旅行字幕，改为「関西周遊」、两章关西内容及本库旅行文字。 | 原因未记录。 |
| 照片、动画与地图 | 原片实拍、动画回忆与城市镜头，改为 `film/scenes.js` 绘制的卡片、插画和照片风格画面，以及 MapLibre / OpenFreeMap 地图。 | 原因未记录。 |
| 音乐与字幕 | 原片音乐、歌词改为 `film/config.js` 的 Kansai Loop 原创配乐、字幕与到站提示音。 | 原因未记录。 |
| 卡片到全屏 | 原片以硬切为主；当前为 600ms 连续展开与压暗层。 | 原因未记录。 |
| 收集托盘 | 原片角色缩略图托盘，改为与步进器同列的四枚车站印章。 | 原因未记录。 |
| 竖排地名与时序 | 原片使用粗黑体，当前使用明朝体；具体缓动与毫秒数按观察拟合。 | 字体替换原因未记录；参考资料只提供成片，缓动数值为本地拟合。 |
| 画幅 | 原片为横屏，当前另有 1080×1920 竖屏布局。 | 接入本库横竖画幅。 |

## 已决定删减

当前收录范围省去原片 DAY 04–07、东京终点及原作四部作品的完整主题与人物内容，删减原因未记录。

## 自行实现

地图镜头、路线、HUD、卡片与程序场景、章节、回忆、分屏、印章、警示、配乐、时间线与横竖布局均由本库代码实现，入口为 `film/config.js`、`film/paths.js`、`film/scenes.js` 与 `film/script.js`。原片用于观察构成与节奏。
