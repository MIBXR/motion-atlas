# 第三方许可索引

[条目来源](../../../entries/cases/map-pilgrimage.json) · [地图资源配置](film/config.js) · [字体栈](film/style.css)

- MapLibre GL JS 5.6.0：[固定版本源码与许可](https://github.com/maplibre/maplibre-gl-js/tree/v5.6.0)。
- OpenFreeMap：[地图服务与来源](https://openfreemap.org/)；OpenStreetMap：[数据许可与署名](https://www.openstreetmap.org/copyright)；OpenMapTiles：[源码与许可](https://github.com/openmaptiles/openmaptiles)。
- Terrain Tiles：[高程数据来源与许可](https://registry.opendata.aws/terrain-tiles/)。
- 字体由 `film/style.css` 的系统字体栈提供：[Microsoft 字体目录](https://learn.microsoft.com/en-us/typography/font-list/)、[Apple 系统字体](https://developer.apple.com/fonts/system-fonts/)、[Noto CJK 来源与许可](https://github.com/notofonts/noto-cjk)、[JetBrains Mono 来源](https://github.com/JetBrains/JetBrainsMono)与[仓库内 OFL 原文](../mg-isometric/fonts/JetBrainsMono-OFL.txt)。
