# 月亮睡不着 · 蜡笔儿童绘本

## 实现 Prompt

制作“月亮睡不着 · 蜡笔儿童绘本”对应的时间线影片。月亮失眠，数羊失败；女孩爬上逐级画出的梯子，用水彩刷显纸上白蜡笔星星，再给月亮盖上拼布被，镜头拉远成桌上的绘本并翻到终页。蜡笔防染成为高潮动作，线条抖动、纸齿、梯子与被子都由绘画材料本身推动故事。视觉与动作：Canvas2D蜡笔丝带、锯齿填色和替换姿势，经WebGL2纸齿附着、防染、凹凸与灯光合成。12fps线条重画与替换动作，24fps相机和水彩前沿；画出梯子、涂上被子、拉远到书与条带仿射翻页。配色：暖纸 #f4efe3、靛蓝轮廓 #2d3263、黄 #f5c63c、红 #d4483c、天蓝 #79acd9与白蜡 #fbfaf4，夜色只用群青水彩。文字：Patrick Hand 400作字幕和书页文字，Gaegu 400/700作手写标题和终页。声音：原作音乐盒、玩具钢琴、长笛、单簧管与钟琴摇篮曲，Kokoro af_heart旁白，蜡笔、水彩、毛毡与翻页拟音。直接使用demos/cases/lemo-crayon-book/film/中的原作绘制与时间表，按源码迁移字段修改，支持MotionKit播放、暂停和逐帧定位，声音默认关闭。

## 动效 Token

- **镜头与节拍**：12fps线条重画与替换动作，24fps相机和水彩前沿；画出梯子、涂上被子、拉远到书与条带仿射翻页。

## 制作约束

- 水彩只覆盖画页与背景，角色在水彩后合成。
- 纸齿固定在画页，缩放时交叉淡化噪声倍频。
- 白蜡笔图案与水彩使用同一覆盖场。

## 迁移

- `film/film.js → LINES / camT / RUNG_T`：修改故事文案、相机与画梯动作。
- `film/world.js → STARS / BANDS；film/gl.js → wash`：修改隐藏图形、刷色时段与蜡笔防染强度。
