# 走向远山 · 浮世绘

## 实现 Prompt

制作“走向远山 · 浮世绘”对应的时间线影片。戴笠旅人走过稻田、雨桥与茶屋，巨浪冲出画框并洗回空纸；四次套印重新显出山景，镜头拉远露出五景画轴。五幅版画以同一座山组织构图，色版、装裱留缝与纸白同时承担造型、转场和高潮。视觉与动作：Canvas2D色版缓存，木纹、巴连擦痕、胡麻摺斑点、薄纤维与逐像素ぼかし渐层。逐版套印、横向手卷、浪峰抬镜与冲入泡沫、对数尺度拉远。配色：和纸 #eee2c6、普鲁士蓝 #1d3a66、墨 #231f1c、朱红 #b8412f、赭黄 #cf9f4a与草绿 #8aa152。文字：Shippori Mincho B1 500/600/700、Yuji Syuku 400；横向字幕签、竖排景名与朱印。声音：原作三味线、尺八、太鼓、拍子木配乐，Kokoro am_adam旁白，纸木水声与巨浪后的绝对静默。直接使用demos/cases/lemo-ukiyoe/film/中的原作绘制与时间表，按源码迁移字段修改，支持MotionKit播放、暂停和逐帧定位，声音默认关闭。

## 动效 Token

- **镜头与节拍**：逐版套印、横向手卷、浪峰抬镜与冲入泡沫、对数尺度拉远。

## 制作约束

- 色版分别缓存，保持套印偏移与纸齿。
- 波峰越界时同时避开纸面与边框裁切。
- 修改文字后同步字体字符子集。

## 迁移

- `film/story.js → T / SLOT / SW`：修改五景时刻、转场、套印和画卷间距。
- `film/views.js / wave.js / traveler.js`：修改景物、浪形与旅人姿势。
