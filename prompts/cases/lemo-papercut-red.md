# 年兽进城 · 红色窗花剪纸

## 实现 Prompt

制作“年兽进城 · 红色窗花剪纸”对应的时间线影片。年兽进村，灯火逐盏熄灭；女孩把红纸折三次、剪出楔形图案，展开后八盏灯笼飞向八扇窗，窗花镂空的光落在雪地与年兽脸上。折、剪、展开直接推动故事；同一个楔形图案既复制灯笼，也成为照亮村落与驱散年兽的孔洞光。视觉与动作：Canvas2D纸片、阴刻与阳刻孔洞、关节纸偶、夜景光图和背光窗花。三次折纸、剪刀轨迹遮罩、三次展开、八盏灯笼飞出、昼夜纸张揭离与结尾窗花拉远。配色：红纸 #d2201f、年兽深红 #b00f26、米纸 #f2e8d0、夜纸 #1c2446与结尾金箔 #d9a93f。文字：Fraunces可变衬线与Ma Shan Zheng 400；镂空标题、锯齿横批字幕与年字印。声音：原作琵琶、筝、二胡、笛和锣鼓配乐，Kokoro af_sarah旁白，剪纸、折痕、蜡烛与鞭炮拟音。直接使用demos/cases/lemo-papercut-red/film/中的原作绘制与时间表，按源码迁移字段修改，支持MotionKit播放、暂停和逐帧定位，声音默认关闭。

## 动效 Token

- **镜头与节拍**：三次折纸、剪刀轨迹遮罩、三次展开、八盏灯笼飞出、昼夜纸张揭离与结尾窗花拉远。

## 制作约束

- 夜景背景使用靛蓝纸，红纸主体保留轮廓。
- 镂空使用不透明蒙版，折叠厚度只画在未剪区域。
- 图案投光读取团花孔洞与人物alpha。
