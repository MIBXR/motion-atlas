# 雨的颜色 · 油画厚涂

## 实现 Prompt

制作“雨的颜色 · 油画厚涂”对应的时间线影片。灰色雨中，大提琴手无人聆听，女孩撑开第一把红伞；圆舞曲让雨伞逐拍染色，俯拍下的群伞轨迹在地面累积成曼陀罗，终和弦把广场重涂成彩色。同一组厚涂笔触保存灰与彩两种状态，音乐既推动换色，也让人群运动留下可读的彩色图案。视觉与动作：WebGL2双倍超采样的颜色与高度场，刮刀斜面、颜料脊、薄底画与横向湿地反光。音乐拍点撑伞与换色，镜头推、横移、仰抬、旋转俯拍与吊臂拉远，笔触扫入转场。配色：钴蓝 #34507e、桃色 #d99a78、金色 #f7dca0与赭色外墙；雨伞用红 #dc2f28、黄 #f4bc2a、蓝 #2f62c0、绿 #23906c等高纯色。文字：Cormorant Garamond斜体300–700、Cormorant SC 500；大标题由刮刀铺出，片尾小字用DOM。声音：原作无旁白；大提琴、手风琴、拨弦、竖琴、钟琴与打击采样，配雨、湿石脚步、尼龙伞和刮刀拟音。直接使用demos/cases/lemo-impasto/film/中的原作绘制与时间表，按源码迁移字段修改，支持MotionKit播放、暂停和逐帧定位，声音默认关闭。

## 动效 Token

- **镜头与节拍**：音乐拍点撑伞与换色，镜头推、横移、仰抬、旋转俯拍与吊臂拉远，笔触扫入转场。

## 制作约束

- 同一笔触保持固定种子，静态颜料保持静止。
- 笔触按形状分组，人物与伞使用较低run-out。
- 相机保持在画板范围内，成片不加额外颗粒。

## 迁移

- `film/timeline.js → A / B / T / POPS`：修改音乐网格、镜头与逐拍撑伞。
- `film/film.js → DANCE / dancePos / shotTop`：修改群伞队形、轨迹累积和俯拍镜头。
