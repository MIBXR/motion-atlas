# 一百个夏天 · 数据叙事

## 实现 Prompt

以一百个夏天 · 数据叙事的原作源码实现完整时间线影片。铅笔把1926—2026年的夏季温度逐点画成一位女性的一生：蓝色人生批注进入后，红色记录批注随升温加密，数据破框、铅笔翻到红头，点线最后化为温度条纹。Canvas2D 原作纸纹、铅笔、逐点图表与手写批注；GISTEMP v4 JJA 原始表和提取数据。逐点描图与跟笔，破框急推和翻笔，静默后末点独奏，101个点按年份扫过并伸展为条纹。暖纸、石墨、蓝红双头铅笔和以0.22°C为中心的冷暖色坡。Newsreader 正体与斜体可变字重，Caveat 500，IBM Plex Mono 400／500。原作90BPM数据音高映射、从四分至三十二分音符的加密、环境拟音和 Kokoro af_alloy 旁白。画面直接执行film/中的原作render(t)，按24fps定位，声音默认关闭。

## 动效 Token

- **第一个点**：0.000—2.667秒
- **标题与坐标轴**：2.667—5.333秒
- **人生逐点描绘**：5.333—20.167秒
- **升温攀爬**：20.167—26.667秒
- **破框翻笔**：26.667—28.667秒
- **密集记录**：28.667—31.000秒
- **静默硬切**：31.000—32.000秒
- **最后一点**：32.000—34.000秒
- **全图展开**：34.000—37.333秒
- **点线转条纹**：37.333—40.000秒
- **拉入更长记录**：40.000—42.667秒
- **下一格与片尾**：42.667—50.000秒

## 制作约束

- 数据位置、色坡和音高共用真实数值；修改数据后同步生成乐谱。
- 逐字批注保留世界坐标，点线转条纹时继续保持年份对应。
