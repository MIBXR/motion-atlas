# 城市之光，1987 · 80 年代赛璐璐动画

## 实现 Prompt

制作一支80 年代赛璐璐动画时间线影片。快递少女穿过雨夜霓虹都市，在吊桥升起前飞跃缺口，把磁带送到火箭驾驶员手中；磁带按下播放，城市在黎明中放亮。绘景、平涂赛璐璐、透过光与录像带显像管四层反差；抽帧人物置于连续镜头、霓虹和雨线之中。画面构成：夜景靛蓝、紫、霓虹洋红与青；黎明改为玫瑰、桃色和浅金；珊瑚围巾贯穿。；Kanit粗斜体镀铬片名、Dela Gothic One日文、Barlow Semi Condensed字幕。；1920×1080全画幅；长绘景与近景人物对照，底部留字幕带。；缓存彩色与自发光画板，硬阴影平涂人物，WebGL录像带与显像管后期。；多速视差、12/8fps作画、连续扫光与雨、冲击帧和慢摇静帧。；原片116BPM城市流行配乐、模拟合成器、引擎与磁带拟音、双声线旁白。；按小节切镜，飞跃前一拍静音，机舱播放磁带后升半音进入尾段。；磁带既是递送目标也改变配乐音质；夜骑与黎明骑行共享构图。。实现入口为demos/cases/lemo-cel-anime-80s/film/，MotionKit适配层仅调用并等待原作render(t)，使用原片音轨同步播放。

## 动效 Token

- **多层摇降**：film/scenes1.js:crane：yF=−k×(3200−1080)，yN=−k×(3600−1080)，yFG=−3400k+900。
- **抽帧作画**：film/story.js:q12 / q8：floor(t×12+1e−6)/12、floor(t×8+1e−6)/8；eyes三张睁眼画。
- **扫光星芒**：film/scenes1.js:titleCard：倾斜光带与flare；film/post.js保持原作自发光合成。

## 制作约束

- 人物和背景发光板分层，角色遮挡发光层。
- 抽帧只用于角色表演，镜头与扫光连续。
- 保持字体字重和日文字形覆盖。
