# 二十一键 · 产品拆解

## 实现 Prompt

以二十一键 · 产品拆解的原作源码实现完整时间线影片。开源分体键盘的一半在一次连续镜头中按真实层次升起，镜头进入板下查看主控、灯珠与热插拔，再按从底到顶的顺序合拢，在实物上画出尺寸。three.js r170 物理材质；原作 pcb.json、crkbd 固定版本 STEP 三角网格和 Poly Haven 棚拍 HDRI。键帽按距离错峰，六层沿组装轴升起；单调相机插值穿入板下，底层先合拢，尺寸线按端点投影生长。石墨渐变背景、暖白标注、橙色键帽与尺寸线。Noto Sans SC 400／500，JetBrains Mono 可变字重，Inter 可变字重。原作96BPM配乐与 CC0 乐器采样、塑料与金属拟音、Kokoro am_michael 旁白。画面直接执行film/中的原作render(t)，按24fps定位，声音默认关闭。

## 动效 Token

- **键帽微距**：0.000—2.500秒
- **真实按键**：2.500—4.400秒
- **留白**：4.400—5.000秒
- **逐层升起**：5.000—7.500秒
- **六层引线**：6.900—11.900秒
- **进入缝隙**：12.500—15.000秒
- **主控**：15.000—18.100秒
- **灯珠**：18.100—21.300秒
- **穿过定位板**：21.300—22.300秒
- **热插拔**：22.300—25.000秒
- **合拢**：25.000—27.600秒
- **实物尺寸**：27.500—33.700秒
- **片尾**：33.750—38.750秒

## 制作约束

- 几何与标注沿用 foostan/crkbd 固定提交，尺寸事实见 source/FACTS.md。
- 保留2倍渲染与原作景深、AO、灯光和后期参数。
