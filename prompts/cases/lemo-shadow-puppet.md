# 后羿射日 · 皮影戏

## 实现 Prompt

制作“后羿射日 · 皮影戏”对应的时间线影片。十盏幕后油灯化作十个太阳，后羿每射落一日便熄灭一灯；留下最后一日后，镜头绕到幕后，显出独灯、操偶手与皮影幕布。灯数决定世界亮度，射日动作让过曝白热逐级回到暖金，结尾把神话与皮影照明收在同一盏灯上。视觉与动作：Canvas2D镂刻皮片、布纹与杆件，WebGL2灯场乘透射并进行暖色辉光合成。手颤、压幕与离幕虚化、定式急推、箭头甩镜、锁定广角的九级暗化与幕柱遮挡。配色：朱红 #b8211a、火橙 #d9541c、赭黄 #dc9d1e、石绿 #236e3a、靛蓝 #22647e，暖灯透过生皮色 #e2bd80。文字：Cormorant Garamond 500/600/700、斜体600，Ma Shan Zheng 400；刻字牌匾与讲述者字幕板。声音：原作锣鼓、二胡与管乐采样配乐，Kokoro am_michael旁白，醒木、弓弦、灭灯与皮革拟音。直接使用demos/cases/lemo-shadow-puppet/film/中的原作绘制与时间表，按源码迁移字段修改，支持MotionKit播放、暂停和逐帧定位，声音默认关闭。

## 动效 Token

- **镜头与节拍**：手颤、压幕与离幕虚化、定式急推、箭头甩镜、锁定广角的九级暗化与幕柱遮挡。

## 制作约束

- 皮片叠色保留multiply与透明镂空。
- 弓弦、箭尾和瞄准方向读取同一骨骼解。
- 灯数驱动曝光与幕布亮度，暖色灯光保持一致。

## 迁移

- `film/story.js → T / KILL / SHOTS`：修改灯的点亮、命中、静默与镜头时刻。
- `film/main.js → lampI / renderBack；film/houyi.js`：修改灯场、幕后构图与角色骨骼。
