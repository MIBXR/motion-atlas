# 绕远路回家 · 丝印旅行海报

## 实现 Prompt

制作一支丝印旅行海报代码影片。一位旅人从北京出发，途经伊斯坦布尔、巴黎与布宜诺斯艾利斯；票根数着离家距离，越过世界的另一侧后沿夜海回到北京。以满幅丝印、屏幕固定票根和多层松版串起城市；同一座天坛从晨光换到暮色和夜色，锁版对应归家。每城一套4–6色不透明油墨；奶油纸白承担建筑、星点和水面亮部，暮色与夜色重印同一几何。城市海报铺满1920×1080，标题印在天空；右侧票根350×556，位于1478、236，跨镜保持屏幕位置。线性拉印、斜刮板换城、巴黎吊臂、夜海横移；景层按深度松开，归家重拍收拢。字体：Big Shoulders Display 800/900城市名和数值；Outfit 500/600/700标签；Noto Sans SC 600中文。声音：Kokoro bf_emma旁白，尼龙吉他、手风琴、口琴与低音采样；刮板、网框、夹具及城市环境拟音。按film目录的原作render(t)组织镜头与动作，采用MotionKit时间线逐帧定位，声音默认关闭。

## 动效 Token

- **换城刮板**：film/film.js:183–204、303–312：swRegion旋转裁切，PAR.swap=.5秒，BA.swap=.6秒；刮板后绘完整新城市。
- **松版与锁版**：film/film.js:261–296：巴黎cy=1080→540，景层off按depth分离；HOME.snap=36.6667秒，sep与off回0，基准reg=.35。

## 制作约束

- 改字体与文案时按原作字体载入和子集范围同步取得资源。
- 图形、着色器与时间线通过film内原作render(t)绘制，音轨沿用成片混音。

- `film/film.js → PAL / PAR / BA / HOME`：修改城市色板、换景时刻、距离与归程。
