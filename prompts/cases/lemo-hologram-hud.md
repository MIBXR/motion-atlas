# 伏特·规格扫描 · 科幻全息界面

## 实现 Prompt

以伏特·规格扫描 · 科幻全息界面的原作源码实现完整时间线影片。电助力车从扫描线中长成发光线框，依次锁定电池、电机和刹车，局部爆炸、引线与乱数读数给出规格；归拢后点亮实体全息并完成一圈转台。原作 Canvas2D 三维投影；volt.json 提供车架、车轮、电池、电机与刹车的顶点、边和面。扫描生长，框线由1.9倍与45°回正，轴向局部爆炸，五子帧急摇，读数归栏与实体转台。近黑舞台，188°青色光线，38°琥珀规格值。Rajdhani 300／400／500／600，Share Tech Mono 400。原作合成配乐、机械拟音与 Kokoro af_heart 旁白。画面直接执行film/中的原作render(t)，按24fps定位，声音默认关闭。

## 动效 Token

- **扫描入场**：0.000—2.600秒
- **电池**：8.000—14.000秒
- **电机**：14.000—18.000秒
- **刹车放大镜**：18.000—22.000秒
- **归拢**：22.000—24.000秒
- **实体全息转台**：24.000—28.000秒
- **规格落版**：28.000—34.000秒
- **扫描擦除与片尾**：34.000—39.000秒

## 制作约束

- 规格卡与模型分居两侧，读数在侧栏继续保留。
- 改变模型时同步修改 content.json 的 part 引用与相机目标。
