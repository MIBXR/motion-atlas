# 被落下的伞 · 象形运动图形

## 实现 Prompt

制作一支象形运动图形代码影片。一把黄伞被落在公交车上，晴天里随车到终点，加入失物招领的312把伞；暴雨回来，313把伞同时撑开、变黄，伞墙成为网格纹样，再把干燥脚印送回雨中。同一套圆盘、半圆、胶囊与圆头线构成伞、公交、天气和纹样；一个物件的故事从单个象形符号扩大到整墙。海军蓝、青绿、天蓝、珊瑚、信号黄与暴雨深墨各五阶；黄伞在早段是唯一暖色。1920×1080、24fps；180px网格六行，标题与图符舞台分列，角落LINE 4时钟、章节天气与12站刻度。横向整行交错、网格翻转、列坠落和四分圆切换；313把伞逐圈开合、按行变黄，再在半格错动中成为纹样。字体：Inter Tight 900巨型标题；Noto Sans SC 700/900中文；DM Mono 500的HUD、标签和英语字幕。声音：Kokoro bf_emma旁白，电子底鼓、马林巴、钟琴、弓奏颤音琴和低音采样；开伞、脚步、公交、百叶门、雨与雷拟音。按film目录的原作render(t)组织镜头与动作，采用MotionKit时间线逐帧定位，声音默认关闭。

## 动效 Token

- **伞墙成纹**：film/film.js:476–512、643–655：20×16格、格90，七格杂物、313把伞；bloomOpen按距离延迟.014，37.5秒起按行变黄。
- **计数落定**：film/film.js:523–548：22.1–24秒按o3从1计到313；24秒起scale=1+.07×exp(−9Δt)，以90、470为锚点。

## 制作约束

- 改字体与文案时按原作字体载入和子集范围同步取得资源。
- 图形、着色器与时间线通过film内原作render(t)绘制，音轨沿用成片混音。
