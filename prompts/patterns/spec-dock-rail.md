# 读数停驻再入侧栏

## 实现 Prompt

以来源案例lemo-hologram-hud的原作render(t)重放“读数停驻再入侧栏”。规格大卡依次给出电池、电机与刹车读数；各段结束前大卡淡出，读数芯片从x140滑到x110并在左侧栏累计保留至扫描片尾。 参数：大卡读数roll区间10—11、15.5—16、19.5—20秒；开始淡出13.6、17.6、21.6秒；芯片13.75—14.1、17.75—18.1、21.75—22.1秒入栏。；railY=470+i×min(112,410/(n−1))；n=3时步长112px；x=lerp(140,110,eo(inA))；34秒后HUD随片尾扫描淡出。。按入口segments映射原片，复用原作素材、字体与同段音轨，声音默认关闭。

## 参数

- **原片重放区间**：10.000—22.200秒；28.000—34.000秒，1倍速。
