# 像素对话框

## 实现 Prompt

通过来源 PIXEL QUEST 的 renderAt(t) 重放像素对话框，按 config.js 的 segments 以 1 倍速播放原片 4.4–6.1 秒，声音使用同一区间原片音轨且默认关闭。4.6 秒起框高依次 10、20、30，前两级各 2 帧；框宽 176、x72、y0=99-(h>>1)。全高后显示 56×13 的宝箱名牌、24×20 头像框和指向宝箱的尾角。4.8 秒起使用原作 12px 中文像素字体，每 3 帧揭示一字，字距 1，按 n=min(9,floor((f-fType)/3)+1) 显示「欢迎来到像素世界！」。读完提示保留原作 f>=fType+27 与 ((f>>2)&1)===0 的门限，3 行三角顶宽 5。5.8 秒起按 [20,10,4] 收起，5.9 秒停止显示。继续调用原片代码与字体，使用横屏、时间定位、播放暂停和减少动态偏好。

## 参数

- **原片重放区间**：4.4–6.1 秒，1 倍速，巧思时长 1.7 秒
- **阶梯展开**：原片 4.6 秒起，高度 10、20、30；前两级各 2 帧；宽 176、x72，y0=99-(h>>1)
- **说话者映射**：全高后显示 x82、56×13 名牌，24×20 头像框与指向宝箱的尾角；中文 12px
- **中文逐字**：原片 4.8–5.6 秒，每 3 帧揭示一字；n=min(9,floor((f-fType)/3)+1)，字距 1
- **读完提示**：f>=fType+27 且 ((f>>2)&1)===0 时绘 3 行三角，顶宽 5；默认绘制 f171，f172–173 隐藏
- **阶梯收起**：原片 5.8 秒起，高度按 [20,10,4] 逐帧收起；f177，即 5.9 秒起停止显示
