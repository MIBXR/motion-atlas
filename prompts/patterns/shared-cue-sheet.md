# 画音共用节拍表

## 实现 Prompt

通过 MotionKit.replay 引用五个来源案例的原作、字体、素材与成品音轨，以 index.html 内联配置 的 segments 依次重放密集节点段。保持1920×1080、30fps；画面调用原作 renderAt(t)，音轨使用同一时刻映射。扁平矢量保留180、195、210、225帧四个图标落点；包豪斯保留120BPM与6–8秒的级联；像素片保留6.4秒开箱、6.8秒接物和7.2秒片名。说明层使用中文显示当前 cue 名，声音默认关闭。 总时长12.892秒；末尾依次追加逐帧手绘5.3–9.075秒、线条艺术1.883–5.100秒，原有三段保持。逐帧手绘沿用同一film/cues.json的旋转、爆炸和逐笔书写时刻；线条艺术同时共享笔尖速度与转角数据，中文节点显示停笔和续笔。

## 参数

- **画面时间基准**：1920×1080、30fps；原作帧号除以30换算为秒。
- **扁平矢量落点**：180、195、210、225帧；6、6.5、7、7.5秒。
- **包豪斯级联**：120BPM；R1=6、R2=6.5、R3=7.2、R4=7.5秒，8秒定格。
- **像素开箱节点**：6秒震箱；6.2、6.3秒箱盖跳动；6.4秒开箱；6.8秒接物；7.2秒片名。
- **逐帧手绘节点**：120BPM、24fps；6.5秒爆炸，7.25–8.5秒每0.125秒一笔。
- **线条路径数据**：速度差分dt=1/600；按120Hz采样，CORN[i]>0.05且TD[i]-lastT>0.05时导出转角。
- **总时长**：12.892秒；保留原三段，末尾追加逐帧手绘和线条艺术。
