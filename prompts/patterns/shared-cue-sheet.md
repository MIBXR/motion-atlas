# 画音共用节拍表

## 实现 Prompt

复制三个来源的原作、字体、素材与成品音轨，以 config.js 的 segments 依次重放密集节点段。保持1920×1080、30fps；画面调用原作 renderAt(t)，音轨使用同一时刻映射。扁平矢量保留180、195、210、225帧四个图标落点；包豪斯保留120BPM与6–8秒的级联；像素片保留6.4秒开箱、6.8秒接物和7.2秒片名。说明层使用中文显示当前 cue 名，声音默认关闭。

## 参数

- **画面时间基准**：1920×1080、30fps；原作帧号除以30换算为秒。
- **扁平矢量落点**：180、195、210、225帧；6、6.5、7、7.5秒。
- **包豪斯级联**：120BPM；R1=6、R2=6.5、R3=7.2、R4=7.5秒，8秒定格。
- **像素开箱节点**：6秒震箱；6.2、6.3秒箱盖跳动；6.4秒开箱；6.8秒接物；7.2秒片名。

## 迁移

- `config.js → segments / cues`：设置来源片段与中文节点名称，画面和原音轨使用同一时刻映射。
