# 图表拉远成装置

## 实现 Prompt

用来源案例的原作render(t)实现“图表拉远成装置”。镜头从数据单元的近景持续拉远和升高，已见过的堆片和刻度显出一件完整实体装置，两条年份螺旋连成胡桃木表盘。保留参数：film/film.js:CAMK / setCamera，30秒开始吊臂拉远，q(13,2)=33.75秒相机半径6.6、高度19.6，DUR时半径6.8、高度20，近俯视露出表盘。。按index.html内联segments定位原片，复用原作素材、字体与同区间音轨，声音默认关闭。

## 参数

- **原片重放区间**：lemo-data-physical：29–37.8秒；1倍速，总时长8.800000秒。
