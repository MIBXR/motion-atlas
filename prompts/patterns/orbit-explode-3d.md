# 环绕中逐层爆炸再合拢

## 实现 Prompt

以来源案例lemo-teardown的原作render(t)重放“环绕中逐层爆炸再合拢”。键盘一半在同一三维空间中逐层沿装配轴分离；相机连续环绕、进入层间并停在主控等部件上，最后拉回并从底层开始合拢。 参数：OFF为0/10/18/34/50/70/80/92/116mm；UP从5秒起，UPDUR=1.25，WAVEUP=.45；DOWN从25.63秒起，DOWNDUR=1，WAVEDOWN=.36。；CAM从−31°环绕至18°，继而以look关键帧进入PCB下方；GAP额外抬升30mm，GAP2再抬升轴体16mm。。按入口segments映射原片，复用原作素材、字体与同段音轨，声音默认关闭。

## 参数

- **原片重放区间**：4.400—27.600秒，1倍速。
