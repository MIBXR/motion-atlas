# 圆点落字成标

## 实现 Prompt

复用来源案例的原作 window.renderAt(t)，按 index.html 内联配置 的 segments 重放柱条接字干、圆点升空悬停与落字。保留237/30–245/30秒的矩形形变，247→250帧的上升、250→251帧的悬停、251→255帧的下降；上升用 E.outQ，下降用 E.inQ。落字后按 abs(L.i-4) 帧延迟把10像素冲量传到各字母，保留1.22倍镜头推近、r60→1100的扩散环、持续5帧的六条放射线，以及9.000秒和9.500秒的回跳。沿用原画面、字体与成品音轨，保持1920×1080、30fps；画面和音轨共用同一时刻映射，声音默认关闭。

## 参数

- **柱条接字干**：237/30–245/30=7.900–8.167秒；源框x558…642、y170…460、rx24；p=E.ioC(inv(237/30,245/30,t))。
- **字点升空与落字**：245/30–247/30=8.167–8.233秒蓄力；247→250帧上升，250→251帧悬停，251→255帧下降；AP.y=TIT.y-210；升段E.outQ，降段E.inQ。
- **字干压缩**：stem=.12*kick(t,dl,3.5,.4)+.07*an-.05*kick(t,lau,4,.4)；sx=1+.5*stem，sy=1-stem；基线548。
- **逐字冲量**：dip=10*kick(t,dl+F(abs(L.i-4)),3.2,.4)；字母基线WBASE+dip；每字延迟abs(i-4)/30秒。
- **镜头推震**：下落push=.22*E.inC(inv(dotDrop,dotLand2,t))；落地后.22*(1-spring(t-dl,4.5,.48))；慢推1+.045*E.ioQ(inv(dl,10.4,t))。
- **落字扩散环**：255/30=8.500秒起；r60→1100、线宽24、10帧。
- **落字放射线**：角度-168/-128/-100/-80/-52/-12度；长度76/104/88/110/92/72；线宽14；持续5帧。
- **按拍回跳**：270/30=9.000秒、285/30=9.500秒起；hop+=16*hump(E.outQ(inv(tb,tb+F(9),t)))。
- **末次扩散环**：285/30=9.500秒起；r=DOT_R+14→DOT_R+170、线宽18、12帧。

## 迁移

- `index.html 内联配置 → segments`：设置重放原片的起止时刻，画面与音轨使用同一映射。
- `index.html 内联配置 → markers / reduced`：设置巧思相对时间轴的中文节点与减少动态时刻。
