# 穿窗推镜

## 实现 Prompt

复用来源案例的原作 window.renderAt(t)，按 index.html 内联配置 的 segments 重放穿窗推镜。保留86/30–90/30秒的负向预备、90/30–105/30秒的加速推进与105/30–115/30秒的过冲弹定；缩放按对数尺度计算，NP=2.2、OB=1.2。保留22条分三批出现且各持续2帧的速度条、105帧奶油色闪片、112与113帧的到达镜震，以及115/30–160/30秒的室内续推。沿用原画面、字体与成品音轨，保持1920×1080、30fps；画面和音轨共用同一时刻映射，声音默认关闭。

## 参数

- **预备拉回**：86/30–90/30=2.867–3.000秒；A0=-.05；p=A0*E.ioQ(inv(camAntic,push,t))。
- **连通推进**：90/30–105/30=3.000–3.500秒；S1=1920/64=30；NP=2.2；s=exp(lerp(log(1.12),log(30),p))。
- **过冲弹定**：105/30–115/30=3.500–3.833秒；OB=1.2；kA=NP/(tg-tp)，kB=(OB+3)/(tS-tg)，PG=(kB+A0*kA)/(kA+kB)。
- **放射速度条**：22条；f0=102+i%3；各持续2帧；ra=r0+320*u；len=200+rng*300。
- **穿窗闪白**：fr===105；fill=#FFF6E9；持续1/30=.033秒。
- **到达镜震**：112帧s*=1.03、cy-=9/s；113帧s*=.988、cx+=7/s。
- **室内续推**：115/30–160/30=3.833–5.333秒；s*=1+.14*w；cx=P.x+100/S1*w；cy=P.y-40/S1*w。

## 迁移

- `index.html 内联配置 → segments`：设置重放原片的起止时刻，画面与音轨使用同一映射。
- `index.html 内联配置 → markers / reduced`：设置巧思相对时间轴的中文节点与减少动态时刻。
