# 分层伸展组装

## 实现 Prompt

复用等距 2.5D 来源案例的原作 window.renderAt(t)，依次重放原片1.42–2.57秒土层、1.95–5.45秒楼房、4.325–6.185秒核心塔，时长6.51秒。土层三层分别延迟0/.15/.3秒向下伸展，后续层段的位置由前层当前伸展量计算。楼房基座先落，墙体延后1/30秒以A.spring(tau,14.8,.61,0)长高，roof_lag=.375秒后屋顶落下，细节再延后.05秒弹出，窗光在def.t0+.42秒启亮。核心塔的SH1/SH2/SH3/SHA为2.3/2/1.6/1.2，较细塔段从前段内部升出；按4.625/4.75/5/5.25/5.5/5.75秒组装基座、三段、天线与光环。保留原作模型、材质、字体、逐段上行音与同区间音轨，1920×1080、30fps，声音默认关闭。

## 参数

- **土层**：soil=1.62；三层延迟0/.15/.3秒；高度1.3/.9/.8；s2.y=-1.3*u，s3.y=-1.3*u-.9*u2。
- **墙体**：A.spring(tau,14.8,.61,0)；延后1/30秒；roof_lag=.375；lit0=def.t0+.42。
- **屋顶与细节**：A.drop(tau-rl,.1,.3,0,.025)；A.spring(TGv-b.t0-cues.roof_lag-.05,24,.5,10)。
- **塔段**：SH1=2.3，SH2=2.0，SH3=1.6，SHA=1.2；A.spring(T-tw.seg1,17,.6,5)；seg2.y=top1-SH2+SH2*s2-.02。
- **核心节点**：base=4.625，seg1=4.75，seg2=5，seg3=5.25，antenna=5.5，ring=5.75。
- **时长**：6.51s；原片1.42–2.57、1.95–5.45、4.325–6.185s。

## 迁移

- `config.js → segments`：设置重放原片的起止时刻，画面与音轨使用同一映射。
- `config.js → markers / reduced`：设置巧思相对时间轴的中文节点与减少动态时刻。
