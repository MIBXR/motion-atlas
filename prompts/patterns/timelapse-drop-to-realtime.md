# 延时骤降到实时

## 实现 Prompt

调用来源案例原作render(t)重放“延时骤降到实时”。拥堵密度达到顶点时，×40延时随连续俯冲降到×1，对准鸭子过路的一件小事；静留后释放回×40并升高镜头。 参数：film/story.js:jamRate，22.5–24秒1+39·(1−ss(u))，24–30秒×1，30–30.6秒1+39·ss(u)。 film/main.js:stepped按倍率选8/12Hz或连续时间，jamCam在22.5–24.1秒对数降低高度，look先到鸭子；镜头始终逐帧更新。 使用index.html的segments映射原片时刻，复用来源素材、字体与同区间音轨，声音默认关闭。

## 参数

- **原片重放区间**：lemo-tilt-shift 19.000000–30.800000秒；1倍速，总时长11.800000秒。
