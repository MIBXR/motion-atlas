# 传送门串平行宇宙

## 实现 Prompt

调用来源案例原作render(t)重放“传送门串平行宇宙”。角色冲入传送门，满屏旋涡遮住交接；下一宇宙换成独立的配色、怪物与道具规则，连续短世界沿用相同构图。 参数：film/story.js:WIPES / SHOTS / TAGS；film/main.js:sucked / spit / renderWipe；film/worlds.js各宇宙与portal。 使用index.html的segments映射原片时刻，复用来源素材、字体与同区间音轨，声音默认关闭。

## 参数

- **原片重放区间**：lemo-scifi-toon 12.200000–14.500000秒；lemo-scifi-toon 28.100000–31.700000秒；1倍速，总时长5.900000秒。
