# 火星逐笔写字

## 实现 Prompt

复用来源案例的原作 window.renderAt(t)，按 index.html 内联配置 的 segments 重放原片158/24−0.2至9.075秒，全长2.6916666666666664秒。保留22个火团圆形在0、0.32、0.6、0.82、1的阶梯进度下迁移到rx=520、ry=262的花边徽章；黄色核心以[0,0.55,1]进度和[1,0.45,0.2]尺寸接到第一笔。沿用S=352、gap=18的手绘字形，火星沿E.out2(p)控制的中心线前缀逐笔书写；笔画节点为7.25至8.5秒、间隔0.125秒。保留标题影块、徽章和字面的回弹落定、HAND MADE与中文标语入场。沿用原作字体、纹理和同区间成品音轨，保持1920×1080、24fps，声音默认关闭。

## 参数

- **徽章构成**：C0=[862,614]；BADGE={x:960,y:464,rx:520,ry:262}；N=22；sk=0.14*hs(k,7)。
- **四张聚合**：morphP(t)=t<6.99?0:t<7.07?0.32:t<7.15?0.6:t<7.24?0.82:1。
- **核心点笔**：e=[0,0.55,1][stp]；R=min(q.r*0.8,240)*[1,0.45,0.2][stp]。
- **逐笔书写**：TITLE={cx:960,cy:440,S:352,gap:18}；prefix(full,E.out2(p)*0.999+0.001*p)；strokes=[7.25,7.375,7.5,7.625,7.75,7.875,8,8.125,8.25,8.375,8.5]。
- **回弹落定**：settle=K(t1,[[8.5,0],[8.583,1.25,out2],[8.667,0.9],[8.75,1.0]])；标题缩放1+K(t1,[[8.5,0],[8.54,0.05,out2],[8.625,-0.02],[8.75,0.008],[8.875,0]])。
- **重放时长**：原片158/24−0.2至9.075秒，巧思总时长2.6916666666666664秒。

## 迁移

- `index.html 内联配置 → segments`：设置重放原片的起止时刻，画面与音轨使用同一映射。
- `index.html 内联配置 → markers / reduced`：设置巧思相对时间轴的中文节点与减少动态时刻。
