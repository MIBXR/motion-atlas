# 一词口令即一场

## 实现 Prompt

调用来源案例原作render(t)重放“一词口令即一场”。一个动词同时规定任务、充当字幕并落在关卡下拍；大字砸入后缩为左上角标，在动作发生前让出画面。 参数：film/hud.js:56–80，.12秒1.9→.92、.08秒回1，随后驻留，.22秒缩到.3倍角标；film/timeline.js:cmd与t0共表，film/film.js:cmd_slam事件。 使用index.html的segments映射原片时刻，复用来源素材、字体与同区间音轨，声音默认关闭。

## 参数

- **原片重放区间**：lemo-microgame 0.000000–1.300000秒；lemo-microgame 31.278149–32.578149秒；1倍速，总时长2.600000秒。
