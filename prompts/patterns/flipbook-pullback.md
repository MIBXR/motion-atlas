# 拉远翻纸溯帧

## 实现 Prompt

复用来源案例的原作 window.renderAt(t)，按 config.js 的 segments 重放原片218/24−0.2至232/24+0.2秒，全长0.9833333333333343秒。保留218、220、222帧依次缩至0.9、0.86、0.84的三步拉远，显露灯箱、定位尺与叠纸。224至229帧由拇指掀角翻页，按RIFFLE=[150,121,108,61,30,13]重放旧画格，再回到顶层标题；保留蓝色洋葱皮、透纸灯光和翻页音。张数由drawing(239).id+1-RIFFLE.length给出，圈注在218与220帧分两步完成，并接箭头。沿用原画面、字体与同区间成品音轨，保持1920×1080、24fps，声音默认关闭。

## 参数

- **三步拉远**：pullScale(fq)=fq<218?1:fq<220?0.9:fq<222?0.86:0.84。
- **溯帧序列**：RIFFLE=[150,121,108,61,30,13]；rif=f>=224&&f<=229?f-224:-1。
- **灯箱透光**：[[124,0.14],[80,0.24],[44,0.38]]；洋葱皮偏移[8,-4]与[-5,7]，alpha=0.12与0.16。
- **掀角形状**：a=[350,530,475,560,495,300][rif]*s；b=[250,380,340,405,358,214][rif]*s。
- **总张数圈注**：TOTAL=drawing(239).id+1-RIFFLE.length；p=D.fq>=220?1:0.5；n=44；m=round(n*1.16*p)。
- **重放时长**：原片218/24−0.2至232/24+0.2秒，巧思总时长0.9833333333333343秒。

## 迁移

- `config.js → segments`：设置重放原片的起止时刻，画面与音轨使用同一映射。
- `config.js → markers / reduced`：设置巧思相对时间轴的中文节点与减少动态时刻。
