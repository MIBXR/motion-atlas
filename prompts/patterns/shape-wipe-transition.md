# 形状擦除转场

## 实现 Prompt

复用来源案例的原作 window.renderAt(t)，按 index.html 内联配置 的 segments 重放气泡预备与三段形状擦除。保留144/30–150/30秒的气泡挤压预备，150/30–160/30秒的珊瑚彗星放大旋转，154/30–163/30秒的薄荷胶囊放大旋正，以及158/30–164/30秒的奶油半圆加速砸落与余震。彗星圆半径58、尾长84→204；胶囊3000×1500、rx750；半圆半径1700。沿用原画面、字体与成品音轨，保持1920×1080、30fps；画面和音轨共用同一时刻映射，声音默认关闭。

## 参数

- **气泡预备**：144/30–150/30=4.800–5.000秒；sx乘1+.12*an，sy乘1-.18*an；上提段145/30=4.833秒起。
- **彗星气泡**：150/30–160/30=5.000–5.333秒；圆半径58；k=exp(lerp(log(1.12),log(34),E.ioQ(u1)))；尾长84→204；旋转175*E.outC(u1)。
- **薄荷胶囊**：154/30–163/30=5.133–5.433秒；3000×1500、rx750；k=exp(lerp(log(.03),0,E.ioQ(u2)))；rot=25*(1-E.outB(u2,1.6))。
- **奶油半圆**：158/30–164/30=5.267–5.467秒；半径1700；y=-110-2300*(1-E.inQ(u3))+40*kick(tc,slam,3.5,.4)；sy=1-.06*kick；rot=7*(1-u3)。

## 迁移

- `index.html 内联配置 → segments`：设置重放原片的起止时刻，画面与音轨使用同一映射。
- `index.html 内联配置 → markers / reduced`：设置巧思相对时间轴的中文节点与减少动态时刻。
