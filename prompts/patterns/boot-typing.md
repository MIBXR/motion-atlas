# 终端逐字开机序列

## 实现 Prompt

实现终端逐字开机序列：先按“每字间隔 + 特定字符后停顿”预计算每个字符的出现时刻（如每字 45ms、冒号后停 350ms），渲染与音效共用这份时刻表；输入中显示块状光标，完成后黑底反色闪 180ms 再清空；随后两个圆环以 stroke-dashoffset 900ms 依次描出（第二环延迟 450ms），标志笔画显现；再错峰打出三行身份确认（每字 30ms）。逐字短音用 38ms 方波、三种音高轮替、最短间隔 24ms，默认静音。全部是时间 t 的纯函数，提供跳过与减少动态下的静态完成态。

## 参数

- **每字间隔**：45ms（身份行 30–32ms）
- **停顿**：冒号后 250–350ms，省略号每点 120ms
- **反色闪**：180ms
- **圆环**：900ms inOutCubic，第二环延迟 450ms
- **短音**：38ms 方波，三音高轮替，最短间隔 24ms
